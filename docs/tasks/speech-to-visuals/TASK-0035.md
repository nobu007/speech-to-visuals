## 実装詳細

### 1. レンダラーモジュール実装 🔵

**信頼性**: 🔵 *PIPELINE_FLOW.md Stage 5, api-endpoints.md render-videoより*

Remotionの `renderMedia()` を使用した動画レンダリングモジュール。複数の出力設定に対応する。

- 解像度プリセット: 720p (1280x720), 1080p (1920x1080), 4K (3840x2160)
- フレームレート: 30fps, 60fps
- コーデック: H.264 (AVC), H.265 (HEVC), VP9
- 出力コンテナ: MP4 (H.264/H.265), WebM (VP9)
- レンダリング進捗のコールバック

**実装ファイル**: `src/remotion/renderer.ts`

### 2. 音声トラック統合 🔵

**信頼性**: 🔵 *PIPELINE_FLOW.md Stage 5より*

元の音声ファイル（MP3/WAV）をレンダリング後の動画に統合する機能。

- 元音声の読み込みとエンコード
- 音声トラックの品質設定（AAC 256kbps）
- 音声と映像の同期（キャプション同期機構と連携）
- 音声なし出力のオプション

**実装ファイル**: `src/remotion/renderer.ts`

### 3. レンダリング設定インターフェース 🔵

**信頼性**: 🔵 *api-endpoints.md render-videoより*

API経由でのレンダリング設定を受け付けるインターフェース。

```typescript
interface RenderConfig {
  resolution: '720p' | '1080p' | '4k';
  fps: 30 | 60;
  codec: 'h264' | 'h265' | 'vp9';
  includeAudio: boolean;
  audioBitrate?: string; // default: '256k'
  quality: number; // 1-100, CRF value
}
```

**実装ファイル**: `src/remotion/renderer.ts`

### 4. ファイルサイズ最適化 🔵

**信頼性**: 🔵 *PIPELINE_FLOW.md Stage 5より*

出力ファイルサイズの最適化。5-10MB/分のターゲットを達成するための品質設定。

- CRF（Constant Rate Factor）による品質とファイルサイズのバランス
- 1080p@30fps H.264: CRF 23-28 で 5-10MB/分を目標
- 2パスエンコーディングのオプション
- ファイルサイズ推定ロジック

**実装ファイル**: `src/remotion/renderer.ts`

## 注意事項

- Remotion 4.0 の `renderMedia()` APIを使用すること（旧APIの `renderFrames()` は非推奨）
- サーバーサイドレンダリング環境ではヘッドレスブラウザが必要（`@remotion/renderer` はNode.js環境で動作）
- 4Kレンダリングはメモリ使用量に注意（最低8GB推奨）
- H.265はライセンスに注意し、オープンソース用途ではVP9の使用を検討
- 長時間動画のレンダリングではメモリリークに注意
