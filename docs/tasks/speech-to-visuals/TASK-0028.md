## 実装詳細

### 1. 円形配置アルゴリズム 🔵

**信頼性**: 🔵 *ZERO_OVERLAP_DESIGN.md §3.3 Table, dataflow.md 機能3 図解タイプ別戦略テーブル より*

ノードを円周上に等間隔で配置する。円の中心をキャンバスの中心とし、半径はノード数とノードサイズに基づいて計算する。各ノードの角度は `2π * index / nodeCount` で算出し、等間隔配置を保証する。

- 主戦略: 円形レイアウト（Circular Layout）
- フォールバック戦略: Force-Directed

```typescript
// 円形配置の計算
const centerX = canvasWidth / 2;
const centerY = canvasHeight / 2;
const radius = Math.max(
  maxNodeWidth * nodeCount / (2 * Math.PI) + padding,
  maxNodeHeight * nodeCount / (2 * Math.PI) + padding,
  minRadius
);

for (let i = 0; i < nodes.length; i++) {
  const angle = (2 * Math.PI * i) / nodes.length;
  const x = centerX + radius * Math.cos(angle);
  const y = centerY + radius * Math.sin(angle);
}
```

**実装ファイル**: `src/visualization/strategies/cycle-strategy.ts`

### 2. 等間隔角度の計算 🔵

**信頼性**: 🔵 *ZERO_OVERLAP_DESIGN.md §3.3 Table より*

ノード数に基づいて等間隔角度を計算する。N個のノードの場合、各ノード間の角度は `2π / N` となる。ノードのラベルテキストに基づいてノード幅を計算し、隣接ノードと重ならない最小半径を決定する。

**実装ファイル**: `src/visualization/strategies/cycle-strategy.ts`

### 3. エッジの円弧表現 🔵

**信頼性**: 🔵 *ZERO_OVERLAP_DESIGN.md §2 より*

円周上のノード間のエッジを描画する。隣接ノード間は円弧に沿って描画し、非隣接ノード間は直線またはベジェ曲線で描画する。エッジが円の内部を通る場合は、コード（弦）として描画する。エッジの方向を示す矢印を配置する。

**実装ファイル**: `src/visualization/strategies/cycle-strategy.ts`

### 4. Force-Directed フォールバック 🔵

**信頼性**: 🔵 *ZERO_OVERLAP_DESIGN.md §2.1, dataflow.md 機能3 より*

円形レイアウトでオーバーラップが発生する場合（ノードが大きすぎて円周に収まらない等）、Force-Directed フォールバックに切り替える。円形構造をできるだけ維持しつつ、フォースダイレクト法でオーバーラップを解消する。

**実装ファイル**: `src/visualization/strategies/cycle-strategy.ts`
