## 実装詳細

### 1. ErrorDisplay コンポーネント実装 🟡

**信頼性**: 🟡 *src/quality/enhanced-error-recovery.tsから妥当な推測*

エラー情報を表示するメインコンポーネント。エラー種別に応じた表示の切り替えと、ユーザーアクションの提供を行う。

- エラー種別:
  - `UPLOAD_ERROR`: ファイルアップロード関連
  - `TRANSCRIPTION_ERROR`: 文字起こし関連
  - `ANALYSIS_ERROR`: 図解分析関連
  - `RENDER_ERROR`: 動画レンダリング関連
  - `NETWORK_ERROR`: ネットワーク接続関連
  - `UNKNOWN_ERROR`: 不明なエラー
- エラーアイコン（shadcn/ui Alert コンポーネント）
- エラータイトルとメッセージ
- エラーコードの表示（デバッグ用）
- タイムスタンプの表示

**実装ファイル**: `src/components/ErrorDisplay.tsx`

### 2. RecoveryGuide コンポーネント実装 🟡

**信頼性**: 🟡 *src/quality/enhanced-error-recovery.tsから妥当な推測*

エラー種別に応じたリカバリガイダンスを提供するコンポーネント。ユーザーが次に取るべきアクションを案内する。

- 各エラー種別のリカバリ手順:
  - `UPLOAD_ERROR`: ファイル形式/サイズの確認、再アップロード
  - `TRANSCRIPTION_ERROR`: 音声品質の確認、再実行
  - `ANALYSIS_ERROR`: 音声内容の確認、設定変更
  - `RENDER_ERROR`: 設定の変更、再レンダリング
  - `NETWORK_ERROR`: 接続確認、再接続
- ステップバイステップのガイダンス表示
- リトライボタン（即時リトライ）
- 最初からやり直すオプション
- サポートへの連絡リンク

**実装ファイル**: `src/components/RecoveryGuide.tsx`

### 3. リトライロジック統合 🔵

**信頼性**: 🟡 *src/quality/enhanced-error-recovery.tsから妥当な推測*

エラーからのリトライロジック。SimplePipelineInterface との連携による再実行。

- リトライ回数の制限（最大3回）
- 指数バックオフによるリトライ間隔（1秒、2秒、4秒）
- リトライ回数の表示
- リトライ上限到達時の最終エラー表示

**実装ファイル**: `src/components/ErrorDisplay.tsx`

### 4. エラー詳細表示 🟡

**信頼性**: 🟡 *src/quality/enhanced-error-recovery.tsから妥当な推測*

開発者/高度なユーザー向けのエラー詳細情報の表示。折りたたみ可能なセクションで提供する。

- スタックトレース（開発環境のみ）
- API レスポンスの生データ
- リクエストパラメータ
- 環境情報（ブラウザ、OS等）
- 折りたたみ/展開のトグル

**実装ファイル**: `src/components/ErrorDisplay.tsx`

## 注意事項

- エラーメッセージはユーザーにとって理解しやすい内容にすること（技術的なエラーコードは補足情報として扱う）
- リカバリガイダンスは具体的なアクションを提示すること（「もう一度お試しください」だけでなく、「ファイル形式がMP3であることを確認し、再度アップロードしてください」等）
- セキュリティ上の理由から、本番環境ではスタックトレースやAPIレスポンスの詳細を表示しないこと
- shadcn/ui の Alert, AlertDescription コンポーネントをベースに実装すること
- React 18.3 の Error Boundary との連携を検討すること
