## 実装詳細

### 1. 厳格グリッド配置 🔵

**信頼性**: 🔵 *ZERO_OVERLAP_DESIGN.md §3.3 Table, dataflow.md 機能3 図解タイプ別戦略テーブル より*

ノードを厳格なグリッド上に配置する。主戦略はGrid-Snapのみであり、フォールバック戦略は不要（N/A）である。グリッドセルのサイズは最大ノードのバウンディングボックスに基づいて決定し、全セルが同一サイズであることを保証する。

- 主戦略: Grid-Snap（厳格グリッド配置）
- フォールバック戦略: N/A（グリッド配置で常にオーバーラップ0を保証）

**実装ファイル**: `src/visualization/strategies/matrix-strategy.ts`

### 2. 行列サイズの自動計算 🔵

**信頼性**: 🔵 *ZERO_OVERLAP_DESIGN.md §2.3 より*

ノード数から最適な列数（columns）と行数（rows）を自動計算する。正方形に近いグリッドを優先し、アスペクト比16:9のキャンバスに収まるよう調整する。

```typescript
// 行列サイズ計算例
const aspectRatio = 16 / 9;
const columns = Math.ceil(Math.sqrt(nodeCount * aspectRatio));
const rows = Math.ceil(nodeCount / columns);
```

計算ロジック:
1. ノード数とキャンバスアスペクト比から理想的な列数を算出
2. 列数から行数を算出（`Math.ceil(nodeCount / columns)`）
3. 最後の行が不完全な場合でもグリッド構造を維持

**実装ファイル**: `src/visualization/strategies/matrix-strategy.ts`

### 3. 均等間隔の実現 🔵

**信頼性**: 🔵 *ZERO_OVERLAP_DESIGN.md §2.3 より*

全ノード間の水平・垂直間隔を均等にする。グリッドセルの幅は `(canvasWidth - 2 * padding) / columns`、高さは `(canvasHeight - 2 * padding) / rows` で計算する。ノードは各セルの中央に配置する。

**実装ファイル**: `src/visualization/strategies/matrix-strategy.ts`

### 4. エッジパス計算 🔵

**信頼性**: 🔵 *ZERO_OVERLAP_DESIGN.md §2 より*

マトリックス上のノード間のエッジを描画する。隣接セル間は直線、離れたセル間は折れ線または曲線で接続する。エッジが他のノードと交差する可能性が高い場合は、マンハッタン距離に基づく経路を選択する。

**実装ファイル**: `src/visualization/strategies/matrix-strategy.ts`
