## 実装詳細

### 1. PipelineProgress コンポーネント実装 🔵

**信頼性**: 🔵 *src/components/SimplePipelineInterface.tsx, api-endpoints.md WebSocketイベントより*

パイプライン全体の進捗を表示するコンポーネント。4つのステージの進行状況と全体の進捗を表示する。

- 4ステージ表示: 文字起こし (Transcribe) → 分析 (Analyze) → レイアウト (Layout) → 動画生成 (Render)
- 各ステージの状態: 待機中 (pending) / 処理中 (active) / 完了 (completed) / エラー (error)
- 全体進捗のプログレスバー（0-100%）
- 現在のステージの詳細情報表示

**実装ファイル**: `src/components/PipelineProgress.tsx`

### 2. StageIndicator コンポーネント実装 🔵

**信頼性**: 🔵 *src/components/SimplePipelineInterface.tsxより*

個別ステージの状態を表示するコンポーネント。shadcn/ui の Badge, Tooltip コンポーネントを活用する。

- ステージアイコン（待機/処理中/完了/エラーの各状態）
- ステージ名と説明
- ステージ内の進捗（0-100%）
- 処理時間の表示
- エラー時の詳細情報ツールチップ

**実装ファイル**: `src/components/StageIndicator.tsx`

### 3. ETA計算ロジック 🔵

**信頼性**: 🔵 *api-endpoints.md WebSocketイベントより*

推定残り時間の計算ロジック。各ステージの進捗率と経過時間からETAを算出する。

- 各ステージの平均処理時間に基づく推定
- 現在のステージの進捗率から残り時間を計算
- 残りのステージの推定時間を加算
- ETA のフォーマット（"残り約3分" / "残り約45秒"）
- 初回表示までの最小表示時間（1秒以上経過後に表示）

**実装ファイル**: `src/components/PipelineProgress.tsx`

### 4. 品質スコア表示 🔵

**信頼性**: 🔵 *api-endpoints.md WebSocketイベントより*

分析ステージ完了後の品質スコア表示。

- 品質スコアの表示（0-100）
- スコアに応じたカラーコーディング（高: 緑, 中: 黄, 低: 赤）
- 品質メトリクスの内訳表示（オプション）
- shadcn/ui Progress コンポーネントの活用

**実装ファイル**: `src/components/PipelineProgress.tsx`

### 5. WebSocket イベントリスナー統合 🔵

**信頼性**: 🔵 *api-endpoints.md WebSocketイベントより*

リアルタイム進捗更新のためのWebSocket イベントリスナー。

- イベントタイプ: `pipeline:progress`, `pipeline:stage-complete`, `pipeline:complete`, `pipeline:error`
- イベントデータ: ステージ名、進捗率、ETA、品質スコア
- 接続状態の表示（接続中/切断/エラー）
- 自動再接続ロジック

**実装ファイル**: `src/components/PipelineProgress.tsx`

## 注意事項

- WebSocket イベントリスナーはコンポーネントのアンマウント時に適切にクリーンアップすること
- ETA計算は初期段階で不正確になりやすいため、最小閾値（例: 3秒以上経過後）を設けること
- プログレスバーのアニメーションはCSS transition を使用し、スムーズな更新を実現すること
- React Query の `useQuery` と WebSocket の併用により、フォールバック（ポーリング）を実装すること
- shadcn/ui のコンポーネントを最大限に活用し、デザインの一貫性を保つこと
