## 実装詳細

### 1. SRT形式文字列生成 🔵

**信頼性**: 🔵 *PIPELINE_FLOW.md Stage 1, requirements.md REQ-004 より*

タイムスタンプ付きセグメント配列からSRT形式の文字列を生成する。

- `generateSrt(segments: TimestampedSegment[]): string`: セグメント配列からSRT文字列を生成
- SRTフォーマット仕様:
  - セグメント番号（1から始まる連番）
  - 開始タイムスタンプ → 終了タイムスタンプ（`HH:MM:SS,mmm --> HH:MM:SS,mmm`）
  - 字幕テキスト（1行または複数行）
  - セグメント間は空行で区切り
- 複数行テキストの改行文字処理

**実装ファイル**: `src/transcription/srt-generator.ts`

### 2. タイムスタンプフォーマット 🔵

**信頼性**: 🔵 *PIPELINE_FLOW.md Stage 1, SRT仕様より*

ミリ秒値をSRTタイムスタンプ形式に変換する。

- `formatTimestamp(ms: number): string`: ミリ秒を `HH:MM:SS,mmm` 形式に変換
- ゼロパディング: 時間2桁、分2桁、秒2桁、ミリ秒3桁
- 負の値のハンドリング（0にクランプ）
- 24時間を超える場合のハンドリング

**実装ファイル**: `src/transcription/srt-generator.ts`

### 3. セグメント番号付けとバリデーション 🔵

**信頼性**: 🔵 *PIPELINE_FLOW.md Stage 1 より*

セグメントの番号付けと入力バリデーションを実装する。

- セグメント番号は1から始まる連番で自動採番
- 入力セグメントのバリデーション:
  - 開始時刻 ≤ 終了時刻
  - テキストが空でない
  - セグメントが時間順に並んでいる（警告のみ、自動ソートしない）
- 重複セグメントの検出とマージ

**実装ファイル**: `src/transcription/srt-generator.ts`

## 注意事項

- SRT仕様のタイムスタンプ区切りはカンマ（`,`）であり、ドット（`.`）ではないことに注意
- セグメントのテキストに改行が含まれる場合、SRT形式の改行と区別できるよう適切にエスケープすること
- 入力セグメントが空配列の場合は空文字列を返すこと
- 負のタイムスタンプは0にクランプすること
- タイムスタンプ精度は±50msを保証すること（REQ-004）
