## タスク概要

パイプライン各ステージの品質ゲート管理と品質監視モジュールを実装する。Stage 1では音声長1秒以上、Stage 2ではエンティティ・関係性の完全性、Stage 3ではオーバーラップゼロ、Stage 4-5ではキャプション同期±50msを検証する。リグレッション検出機能（5%以上の劣化でブロック）も含む。

## 実装詳細

### 1. QualityGateクラス実装 🔵

**信頼性**: 🔵 *PIPELINE_FLOW.md §6, QUALITY_METRICS.mdより*

各ステージの品質基準を定義し、評価する品質ゲートモジュール。ステージごとの閾値設定、通過/失敗判定、メトリクス記録を管理する。

```typescript
interface QualityGateConfig {
  stage: number;
  name: string;
  criteria: QualityCriterion[];
  blockingOnFailure: boolean;
  fallbackAction?: 'retry' | 'skip' | 'abort';
}

interface QualityCriterion {
  name: string;
  description: string;
  evaluate: (input: StageOutput) => QualityResult;
  threshold: number;
}

interface QualityResult {
  passed: boolean;
  score: number;
  threshold: number;
  details: string;
}
```

**実装ファイル**: `src/quality/quality-gate.ts`

### 2. 品質ゲート基準定義 🔵

**信頼性**: 🔵 *QUALITY_METRICS.mdより*

各ステージの具体的な品質基準を実装する。

- **Stage 1**: 音声長 >= 1秒、サンプリングレート >= 16kHz、ノイズレベル < -30dB
- **Stage 2**: エンティティ抽出率 >= 80%、関係性完全性 >= 70%、JSONスキーマ準拠
- **Stage 3**: オーバーラップ = 0、タイムライン連続性、セグメント正規化
- **Stage 4**: キャプション同期 ±50ms以内、レイアウト一貫性
- **Stage 5**: 動画解像度 >= 720p、フレームレート = 30fps、オーディオ同期 ±50ms

**実装ファイル**: `src/quality/quality-gate.ts`

### 3. QualityMonitorクラス実装 🔵

**信頼性**: 🔵 *QUALITY_METRICS.mdより*

パイプライン全体の品質監視を行うモジュール。品質メトリクスの記録、リグレッション検出、品質トレンド分析を提供する。

```typescript
interface QualityMonitor {
  recordMetric(stage: number, metric: QualityMetric): void;
  detectRegression(stage: number, currentScore: number): RegressionResult;
  getQualityReport(jobId: string): QualityReport;
  subscribeToAlerts(callback: QualityAlertCallback): void;
}

interface RegressionResult {
  isRegression: boolean;
  previousScore: number;
  currentScore: number;
  degradationPercent: number;
  shouldBlock: boolean; // true if degradation > 5%
}
```

**実装ファイル**: `src/pipeline/quality-monitor.ts`

## 単体テスト要件

### テストケース1: Stage 1 品質ゲート（音声長検証） 🔵

**Given**: 音声ファイルのメタデータが入力される
**When**: 音声長が1秒以上の場合
**Then**: 品質ゲートが通過し、score=1.0で合格を返す

**テストファイル**: `tests/unit/quality/quality-gate.test.ts`

### テストケース2: Stage 2 品質ゲート（エンティティ完全性） 🔵

**Given**: 構造化抽出結果が入力される
**When**: エンティティ抽出率が80%未満の場合
**Then**: 品質ゲートが失敗し、詳細な失敗理由を返す

**テストファイル**: `tests/unit/quality/quality-gate.test.ts`

### テストケース3: Stage 3 品質ゲート（オーバーラップ検証） 🔵

**Given**: タイムラインセグメントが入力される
**When**: セグメント間にオーバーラップが存在する場合
**Then**: 品質ゲートが失敗し、オーバーラップ箇所を特定する

**テストファイル**: `tests/unit/quality/quality-gate.test.ts`

### テストケース4: Stage 4-5 品質ゲート（キャプション同期） 🔵

**Given**: キャプションとタイムラインデータが入力される
**When**: キャプションの同期ズレが±50ms以内の場合
**Then**: 品質ゲートが通過する

**テストファイル**: `tests/unit/quality/quality-gate.test.ts`

### テストケース5: リグレッション検出 🔵

**Given**: 過去の品質スコア履歴が存在する
**When**: 現在のスコアが前回より5%以上劣化している場合
**Then**: リグレッション検出が発動し、shouldBlock=trueを返す

**テストファイル**: `tests/unit/pipeline/quality-monitor.test.ts`
