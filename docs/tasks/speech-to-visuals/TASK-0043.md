## 実装詳細

### 1. PipelineOrchestratorクラス実装 🔵

**信頼性**: 🔵 *PIPELINE_FLOW.md, SYSTEM_CORE.md §3より*

パイプライン全体のライフサイクルを管理するオーケストレータークラス。各ステージの実行、品質ゲートの評価、フォールバックの切り替えを統合的に制御する。

```typescript
interface PipelineConfig {
  stages: PipelineStage[];
  qualityGates: QualityGate[];
  fallbackStrategies: FallbackStrategy[];
  progressCallback?: (progress: PipelineProgress) => void;
}

interface PipelineProgress {
  stage: number;
  stageName: string;
  progress: number;
  status: 'running' | 'completed' | 'failed' | 'fallback';
  message?: string;
}
```

**実装ファイル**: `src/pipeline/pipeline-orchestrator.ts`

### 2. SimplePipeline実装 🔵

**信頼性**: 🔵 *PIPELINE_FLOW.mdより*

単一ファイルの処理に特化したシンプルなパイプライン実装。Stage 1からStage 5までを逐次実行し、中間結果をメモリ上で受け渡す。

```typescript
interface SimplePipelineResult {
  jobId: string;
  status: 'success' | 'partial' | 'failed';
  stages: StageResult[];
  output?: {
    videoUrl: string;
    captionsUrl: string;
    metadata: VideoMetadata;
  };
  errors?: PipelineError[];
  duration: number;
}
```

**実装ファイル**: `src/pipeline/simple-pipeline.ts`

### 3. MainPipeline実装 🔵

**信頼性**: 🔵 *SYSTEM_CORE.md §3より*

バッチ処理・並列実行に対応したメインパイプライン実装。複数ジョブのキューイング、優先度管理、リソース制限を管理する。

interface MainPipelineConfig extends PipelineConfig {

**実装ファイル**: `src/pipeline/main-pipeline.ts`

## 単体テスト要件

### テストケース1: パイプライン全ステージ実行 🔵

**Given**: 有効な音声ファイルが入力として与えられる
**When**: PipelineOrchestrator.execute()を呼び出す
**Then**: Stage 1からStage 5まで順次実行され、最終的に動画URLが返却される

**テストファイル**: `tests/unit/pipeline/pipeline-orchestrator.test.ts`

### テストケース2: 品質ゲート通過・失敗 🔵

**Given**: パイプラインが特定のステージを完了する
**When**: 品質ゲートの評価が実行される
**Then**: ゲート通過時は次ステージへ進行し、失敗時はフォールバックが実行される

**テストファイル**: `tests/unit/pipeline/pipeline-orchestrator.test.ts`

### テストケース3: フォールバック統合 🔵

**Given**: Stage 2（構造化抽出）で品質ゲートが失敗する
**When**: フォールバック戦略がトリガーされる
**Then**: フォールバック先の処理（例: 簡易抽出）が実行され、パイプラインが継続する

**テストファイル**: `tests/unit/pipeline/pipeline-orchestrator.test.ts`

### テストケース4: 進捗コールバック 🔵

**Given**: パイプライン実行中に進捗が変化する
**When**: 各ステージの進捗が更新される
**Then**: progressCallbackが正しいステージ情報・進捗率で呼び出される

**テストファイル**: `tests/unit/pipeline/pipeline-orchestrator.test.ts`
