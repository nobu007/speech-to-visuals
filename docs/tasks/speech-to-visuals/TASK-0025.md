## タスク概要

tree図解タイプの階層レイアウト戦略を実装する。親子関係を明確に維持しながら、ルートノードを頂点とする階層構造を表現する。dagreベースのTB（Top-to-Bottom）階層レイアウトを主戦略とし、収束しない場合はGrid-Snapフォールバックに切り替える。

## 実装詳細

### 1. 階層構造の配置 🔵

**信頼性**: 🔵 *ZERO_OVERLAP_DESIGN.md §3.3 Table, dataflow.md 機能3 図解タイプ別戦略テーブル より*

dagreの `g.setGraph({ rankdir: 'TB' })` を使用し、ルートノードを最上位に配置する階層レイアウトを実装する。ルートノードは入力エッジなしのノードとして自動検出する。複数ルートの場合は仮想ルートノードを作成して統合する。

- 主戦略: 階層レイアウト（Hierarchical Layout）
- フォールバック戦略: Grid-Snap
- dagre `rankdir: 'TB'` による階層配置

**実装ファイル**: `src/visualization/strategies/tree-strategy.ts`

### 2. 親子関係の維持 🔵

**信頼性**: 🔵 *ZERO_OVERLAP_DESIGN.md §3.3 Table より*

親ノードと子ノードの上下関係を厳密に維持する。同じ階層レベルの子ノードは水平に整列させ、兄弟ノード間の最小間隔を保証する。深さが異なるサブツリー間のバランスを取り、左右対称に近い配置を目指す。

```typescript
// dagre設定例
g.setGraph({
  rankdir: 'TB',
  nodesep: 60,
  ranksep: 100,
  marginx: 40,
  marginy: 40,
});
```

**実装ファイル**: `src/visualization/strategies/tree-strategy.ts`

### 3. Grid-Snap フォールバック 🔵

**信頼性**: 🔵 *ZERO_OVERLAP_DESIGN.md §2.3 より*

階層レイアウトでオーバーラップが解消できない場合、Grid-Snap フォールバックに切り替える。親子の上下関係を維持しつつ、グリッドベースでノードを再配置する。階層レベル（Y座標）は固定し、X座標のみグリッドにスナップする。

**実装ファイル**: `src/visualization/strategies/tree-strategy.ts`

### 4. エッジパス計算 🔵

**信頼性**: 🔵 *ZERO_OVERLAP_DESIGN.md §2 より*

親子間のエッジを上→下方向に描画する。直線・折れ線・ステップ線のいずれかをツリーの密度に応じて自動選択する。エッジが他のノードと交差しないよう、可能な限り短いパスを選択する。

**実装ファイル**: `src/visualization/strategies/tree-strategy.ts`

## 単体テスト要件

### テストケース1: 階層構造の維持 🔵

**Given**: ルート1個、子3個、孫6個のツリーグラフ
**When**: TreeStrategy の apply メソッドを実行
**Then**: ルートが最上位、子が中間、孫が最下位に配置されること

**テストファイル**: `tests/visualization/strategies/tree-strategy.test.ts`

### テストケース2: 親子関係の正確性 🔵

**Given**: 親ノードと子ノードのペア
**When**: レイアウト計算を実行
**Then**: 親ノードのY座標が子ノードのY座標より小さいこと（上に配置されること）

**テストファイル**: `tests/visualization/strategies/tree-strategy.test.ts`

### テストケース3: 兄弟ノードの水平整列 🔵

**Given**: 同じ親を持つ複数の子ノード
**When**: レイアウト計算を実行
**Then**: 兄弟ノードのY座標が同一であり、X座標が均等間隔であること

**テストファイル**: `tests/visualization/strategies/tree-strategy.test.ts`

### テストケース4: Grid-Snap フォールバック 🔵

**Given**: 階層レイアウトでオーバーラップが解消できないツリー
**When**: フォールバックが実行
**Then**: Grid-Snap によりオーバーラップが0になり、親子の上下関係が維持されること

**テストファイル**: `tests/visualization/strategies/tree-strategy.test.ts`
