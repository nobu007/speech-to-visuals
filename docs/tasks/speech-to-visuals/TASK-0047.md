## タスク概要

Socket.IO 4.8を用いたリアルタイム進捗通知システムの実装。join:job, leave:job によるジョイルーム管理、job:progress, job:complete, job:error によるジョブ状態通知、file:status によるファイル単位の状態通知、stage:progress によるステージ進捗通知を提供する。

## 実装詳細

### 1. Socket.IO イベントハンドラ 🔵

**信頼性**: 🔵 *api-endpoints.md WebSocketセクションより*

Socket.IO 4.8を使用したイベント駆動のリアルタイム通信ハンドラを実装する。接続・切断の管理、認証ミドルウェアの適用、イベントのディスパッチを担当する。

**実装ファイル**: `src/api/websocket-handler.ts`

```typescript
// イベント定義
// クライアント → サーバー
join:job          → ジョイルーム参加
leave:job         → ジョイルーム離脱

// サーバー → クライアント
job:progress      → ジョブ進捗通知 (progress: number, stage: string)
job:complete      → ジョブ完了通知 (jobId: string, result: JobResult)
job:error         → ジョブエラー通知 (jobId: string, error: ErrorDetail)
file:status       → ファイル状態通知 (fileId: string, status: FileStatus)
stage:progress    → ステージ進捗通知 (stage: string, progress: number, details: StageDetails)
```

### 2. ジョイルーム管理 🔵

**信頼性**: 🔵 *api-endpoints.md ルーム管理セクションより*

ジョブIDごとのSocket.IOルームを管理する。クライアントがjoin:jobで特定ジョブのルームに参加し、leave:jobで離脱する。ルーム参加時に最新のジョブ状態を即座に送信する。

**実装ファイル**: `src/api/websocket-handler.ts`

### 3. 進捗ブロードキャスト 🔵

**信頼性**: 🔵 *api-endpoints.md 進捗通知セクションより*

バッチ処理の進捗变化を検知し、対応するジョイルームにブロードキャストする。ジョブ全体の進捗、ファイル単位の状態変化、ステージごとの進捗をそれぞれ適切なイベントで通知する。

**実装ファイル**: `src/api/websocket-handler.ts`

### 4. 認証・認可 🔵

**信頼性**: 🔵 *api-endpoints.md 認証セクションより*

Socket.IO ミドルウェアによる接続時認証。JWT トークンによるユーザー識別と、ジョイルーム参加時のアクセス権限チェックを実装する。

**実装ファイル**: `src/api/websocket-handler.ts`

### 5. ストリーミング文字起こしイベント 🔵

**信頼性**: 🔵 *要件定義REQ-036・api-endpoints.md WebSocketセクションより*

ストリーミング文字起こしのリアルタイムイベントを追加する。各チャンクの文字起こし完了時にstreaming:segmentイベントでセグメントテキスト・信頼度・進捗を通知し、全体完了時にstreaming:completeイベントで完全な文字起こし結果と統計を通知する。

```typescript
// 追加イベント定義
streaming:segment   → { sessionId, segment, confidence, progress }
streaming:complete  → { sessionId, fullTranscript, statistics }
```

**実装ファイル**: `src/api/websocket-handler.ts`

### 6. エラー回復イベント 🔵

**信頼性**: 🔵 *要件定義REQ-037・api-endpoints.md WebSocketセクションより*

ユーザー主導エラー回復のリアルタイムイベントを追加する。エラー発生時にerror:recoveryイベントで回復オプションを通知し、回復実行後にerror:recoveredイベントで結果を通知する。

```typescript
// 追加イベント定義
error:recovery   → { errorId, category, severity, strategies }
error:recovered  → { errorId, strategy, success }
```

**実装ファイル**: `src/api/websocket-handler.ts`
