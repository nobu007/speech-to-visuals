## 実装詳細

### 1. .env.example テンプレート作成 🔵

**信頼性**: 🔵 *PIPELINE_FLOW.md §8.1・REQ-404・NFR-101 より*

以下の環境変数を .env.example に記載する。

**必須**:
- `GOOGLE_API_KEY`: Gemini API キー
- `SUPABASE_URL`: Supabase プロジェクトURL
- `SUPABASE_ANON_KEY`: Supabase 匿名キー

**オプション**:
- `ANALYSIS_DISABLE_GEMINI`: Gemini無効化フラグ（'1' でルールベース強制）
- `GEMINI_MODEL_OVERRIDE`: Geminiモデル上書き（デフォルト: auto）
- `COMPLEXITY_THRESHOLD`: 複雑度閾値（デフォルト: 0.2）
- `CACHE_SIZE`: キャッシュ最大エントリ数（デフォルト: 200）
- `CACHE_TTL_MINUTES`: キャッシュTTL分（デフォルト: 120）
- `SIMILARITY_THRESHOLD`: キャッシュ類似度閾値（デフォルト: 0.9）
- `PORT`: API サーバーポート（デフォルト: 3001）
- `NODE_ENV`: 実行環境（development/production）

**実装ファイル**: `.env.example`

### 2. 設定スキーマ定義 (src/config/schema.ts) 🔵

**信頼性**: 🔵 *PIPELINE_FLOW.md §5・§8・REQ-404 より*

環境変数のスキーマを定義する。

```typescript
interface ConfigSchema {
  googleApiKey: string;           // 必須
  supabaseUrl: string;            // 必須
  supabaseAnonKey: string;        // 必須
  analysisDisableGemini: boolean; // デフォルト: false
  geminiModelOverride?: string;   // オプション
  complexityThreshold: number;    // デフォルト: 0.2
  cacheSize: number;              // デフォルト: 200
  cacheTtlMinutes: number;        // デフォルト: 120
  similarityThreshold: number;    // デフォルト: 0.9
  port: number;                   // デフォルト: 3001
  nodeEnv: 'development' | 'production' | 'test';
}
```

**実装ファイル**: `src/config/schema.ts`

### 3. 環境変数アクセサ (src/config/env.ts) 🔵

**信頼性**: 🔵 *PIPELINE_FLOW.md §8.1・NFR-101 より*

型安全な環境変数アクセサを実装する。

機能:
- `getConfig()`: バリデーション済み設定オブジェクトを返す（シングルトン）
- `validateConfig()`: 必須環境変数の存在確認とバリデーション
- `parseBoolean(value: string | undefined, defaultValue: boolean)`: 真偽値パース
- `parseNumber(value: string | undefined, defaultValue: number)`: 数値パース
- 必須変数欠落時は Error をスロー（アプリケーション起動を停止）
- 機密値（API キー等）のログマスキング機能

**実装ファイル**: `src/config/env.ts`

### 4. バリデーション機能 (src/config/validate.ts) 🔵

**信頼性**: 🔵 *REQ-404・NFR-101 より*

環境変数値のバリデーションロジックを実装する。

- API キー形式の簡易チェック（空文字列でないこと）
- URL 形式の検証（SUPABASE_URL）
- 数値範囲の検証（COMPLEXITY_THRESHOLD: 0-1, PORT: 1024-65535）
- バリデーションエラー時は具体的なエラーメッセージを出力

**実装ファイル**: `src/config/validate.ts`

### 5. インデックスファイル (src/config/index.ts) 🔵

**信頼性**: 🔵 *architecture.md より*

設定モジュールのバレルエクスポート。

- `getConfig()`, `validateConfig()`, `ConfigSchema` を re-export

**実装ファイル**: `src/config/index.ts`

- `.env` ファイルは `.gitignore` に含めること。絶対にコミットしない
