## 実装詳細

### 1. CI ワークフロー (.github/workflows/ci.yml) 🟡

**信頼性**: 🟡 *CI設定は標準的な GitHub Actions パターンを自動推定*

Pull Request および main ブランチへの push をトリガーとする CI ワークフローを作成する。

トリガー:
- `pull_request`: 全ブランチ
- `push`: `main` ブランチ

ジョブ構成:
- **lint**: ESLint チェック
- **type-check**: TypeScript 型チェック（`tsc --noEmit`）
- **test**: Jest テスト実行（カバレッジ付き）
- **build**: Vite プロダクションビルド

Node.js バージョン: 18（`.nvmrc` または `actions/setup-node` で指定）

**実装ファイル**: `.github/workflows/ci.yml`

### 2. テストワークフロー (.github/workflows/test.yml) 🟡

**信頼性**: 🟡 *テスト自動化設定は標準パターンを自動推定*

テスト専用のワークフロー設定。

機能:
- テストマトリックス: Node.js 18, 20
- カバレッジレポートの生成（Jest `--coverage`）
- カバレッジ閾値の設定（最低80%）
- テスト失敗時のアーティファクト保存（スクリーンショット等）

**実装ファイル**: `.github/workflows/test.yml`

### 3. ビルドスクリプト整備 (package.json) 🔵

**信頼性**: 🔵 *note.md 開発ツール・architecture.md ビルド構成より*

CI/CD で使用する npm scripts の整備。

追加スクリプト:
- `ci:lint`: CI 用 Lint（警告もエラーとして扱う）
- `ci:type-check`: CI 用型チェック
- `ci:test`: CI 用テスト（カバレッジ付き）
- `ci:build`: CI 用ビルド
- `ci`: 全 CI ステップを順次実行
- `test:coverage`: カバレッジレポート生成
- `test:watch`: ウォッチモードでのテスト実行

**実装ファイル**: `package.json`

### 4. Jest カバレッジ設定 (jest.config.ts) 🔵

**信頼性**: 🔵 *note.md 開発ツール・Jest 30 設定より*

Jest カバレッジ設定の追加。

設定:
- カバレッジディレクトリ: `coverage/`
- カバレッジプロバイダー: v8
- カバレッジ対象: `src/` 配下（テストファイル・型定義除く）
- 閾値: グローバル80%以上（branches, functions, lines, statements）
- レポート形式: text, lcov, html

**実装ファイル**: `jest.config.ts`

### 5. .nvmrc ファイル 🔵

**信頼性**: 🔵 *REQ-401（Node.js 18+）・note.md より*

Node.js バージョンの固定化。

```
18
```

**実装ファイル**: `.nvmrc`

## 注意事項

- CI 環境変数（GOOGLE_API_KEY, SUPABASE_URL 等）は GitHub Secrets に設定すること
- テストは実際の API を呼び出さず、モックを使用すること（コスト・レート制限のため）
- カバレッジ閾値は段階的に引き上げることを推奨（初期設定: 80%）
- ビルド成果物は `.gitignore` に含めること
- Node.js バージョンは `.nvmrc` と `package.json` の `engines` フィールドで二重に指定すること
- CI の実行時間は5分以内を目標とすること
