## 実装詳細

### 1. transcribe-audio Edge Function 🔵

**信頼性**: 🔵 *api-endpoints.md Edge Functionsセクション, architecture.md 音声処理セクションより*

Gemini AI を使用した音声ファイルの文字起こし機能。音声ファイルを入力として受け取り、タイムスタンプ付きの文字起こしテキストを返す。多言語対応とノイズ除去を含む。

**実装ファイル**: `supabase/functions/transcribe-audio/index.ts`

```typescript
// 入力
interface TranscribeRequest {
  audioFileUrl: string;    // Supabase Storage の音声ファイルURL
  language?: string;       // 言語指定（デフォルト: auto-detect）
  options?: {
    enableTimestamps: boolean;
    noiseReduction: boolean;
  };
}

// 出力
interface TranscribeResponse {
  text: string;
  segments: Array<{
    start: number;
    end: number;
    text: string;
    confidence: number;
  }>;
  language: string;
  duration: number;
}
```

### 2. generate-scenes Edge Function 🔵

**信頼性**: 🔵 *api-endpoints.md Edge Functionsセクション, architecture.md シーン生成セクションより*

Gemini AI を使用したテキストからのシーンデータ生成。文字起こしテキストを入力とし、視覚的シーン記述、タイミング情報、スタイル指定を含む構造化シーンデータを出力する。

**実装ファイル**: `supabase/functions/generate-scenes/index.ts`

```typescript
// 入力
interface GenerateScenesRequest {
  transcriptionId: string;
  text: string;
  segments: TranscribeSegment[];
  style?: {
    theme: string;
    colorPalette: string[];
    animationStyle: string;
  };
}

// 出力
interface GenerateScenesResponse {
  scenes: Array<{
    id: string;
    startTime: number;
    endTime: number;
    visualDescription: string;
    textOverlay?: string;
    transition: string;
    backgroundColor: string;
  }>;
  totalDuration: number;
  metadata: {
    model: string;
    processingTime: number;
  };
}
```

### 3. render-video Edge Function 🔵

**信頼性**: 🔵 *api-endpoints.md Edge Functionsセクション, architecture.md レンダリングセクションより*

Remotion 4.0を使用したシーンデータからの動画レンダリング。シーンデータを入力とし、指定フォーマットの動画ファイルを生成してSupabase Storageに保存する。

**実装ファイル**: `supabase/functions/render-video/index.ts`

```typescript
// 入力
interface RenderVideoRequest {
  scenesId: string;
  scenes: Scene[];
  outputFormat: 'mp4' | 'webm';
  resolution: {
    width: number;
    height: number;
  };
  quality: 'low' | 'medium' | 'high';
}

// 出力
interface RenderVideoResponse {
  videoUrl: string;        // Supabase Storage の動画ファイルURL
  duration: number;
  fileSize: number;
  format: string;
  thumbnailUrl: string;
}
```

### 4. 認証コンテキスト 🔵

**信頼性**: 🔵 *architecture.md 認証セクションより*

Supabase Auth コンテキストを使用した認証処理。各Edge FunctionのリクエストヘッダーからJWTトークンを取得し、ユーザーを識別する。認証エラー時は401レスポンスを返す。

**実装ファイル**: `supabase/functions/_shared/auth.ts`

### 5. タイムアウト・エラーハンドリング 🔵

**信頼性**: 🔵 *architecture.md エラーハンドリングセクションより*

Deno Runtimeの制約に基づいたタイムアウト処理。各関数に適切なタイムアウト値を設定し、統一されたエラーレスポンスフォーマットでエラーを返す。

**実装ファイル**: `supabase/functions/_shared/error-handler.ts`

## 注意事項

- Deno Runtime環境で動作するため、Node.js固有のAPIは使用しないこと
- Supabase Edge Functions の制限（メモリ、実行時間）を考慮すること
- 共通処理（認証、エラーハンドリング）は `supabase/functions/_shared/` に配置し、各関数からインポートすること
- 環境変数（SUPABASE_URL, SUPABASE_ANON_KEY, GEMINI_API_KEY）はSupabaseシークレットとして管理すること
- レスポンスのCORSヘッダーを適切に設定すること
