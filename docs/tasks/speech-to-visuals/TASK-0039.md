## 実装詳細

### 1. VideoPreview コンポーネント実装 🔵

**信頼性**: 🔵 *architecture.md, note.mdより*

Remotion Player（`@remotion/player`）をラップした動画プレビューコンポーネント。パイプライン完了後のシーンデータを受け取り、リアルタイムプレビューを提供する。

- Remotion `<Player>` コンポーネントの統合
- シーンデータの受け渡し（Composition props）
- プレイヤーサイズのレスポンシブ対応（コンテナ幅に合わせた自動スケーリング）
- プレイヤーの初期設定（自動再生なし、初期フレーム0）

**実装ファイル**: `src/components/VideoPreview.tsx`

### 2. プレイヤーコントロール実装 🔵

**信頼性**: 🔵 *architecture.mdより*

動画プレビューの操作コントロール。Remotion PlayerのAPIを活用した再生制御。

- 再生/一時停止ボタン
- シークバー（フレーム単位のスライダー）
- 現在時刻/総時間の表示（MM:SS形式）
- 再生速度の切り替え（0.5x, 1x, 1.5x, 2x）
- フレームステップ（1フレームずつ進む/戻る）

**実装ファイル**: `src/components/VideoPreview.tsx`

### 3. プレビュー解像度切り替え 🔵

**信頼性**: 🔵 *architecture.mdより*

プレビュー時の解像度切り替え機能。レンダリング品質とパフォーマンスのバランスを調整する。

- プレビュー解像度オプション: 360p, 540p, 720p, 1080p
- デフォルト: 720p（パフォーマンスと品質のバランス）
- 解像度変更時のスムーズな切り替え
- 低スペックデバイスでの自動解像度調整（オプション）

**実装ファイル**: `src/components/VideoPreview.tsx`

### 4. プレビュー状態管理 🔵

**信頼性**: 🔵 *note.mdより*

プレビューコンポーネントの状態管理。再生状態、現在フレーム、解像度等を管理する。

- 再生状態（playing / paused）
- 現在フレーム番号
- 総フレーム数
- ループ再生の有無
- プレビュー解像度の現在値

**実装ファイル**: `src/components/VideoPreview.tsx`

## 注意事項

- `@remotion/player` 4.0 のAPIに準拠すること（`component`, `durationInFrames`, `fps`, `compositionWidth`, `compositionHeight` props）
- Remotion Playerはブラウザ上でリアルタイムレンダリングを行うため、複雑なシーンではパフォーマンスに注意すること
- プレビュー解像度を下げることでパフォーマンスを改善できる
- React 18.3 の `useRef` を使用してPlayerのrefを管理し、API呼び出し（play, pause, seekTo）を行うこと
- shadcn/ui のSliderコンポーネントをシークバーとして活用すること
