## 実装詳細

### 1. BatchOptimizer コアクラス 🔵

**信頼性**: 🔵 *要件定義REQ-047・src/optimization/batch-optimizer.ts・architecture.mdバッチ最適化セクションより*

並列チャンク処理によるバッチ最適化のコアクラス。大量アイテムをチャンクに分割し、設定された並列度で並列処理する。フェイルファスト・進捗コールバック・統計情報を提供する。

**実装ファイル**: `src/optimization/batch-optimizer.ts`

```typescript
interface BatchOptimizerOptions {
  concurrency: number;   // 最大並列チャンク数（デフォルト: 4）
  chunkSize: number;     // チャンクサイズ（デフォルト: 50）
  failFast: boolean;     // フェイルファスト（デフォルト: false）
  onProgress?: (completed: number, total: number) => void;
}

interface BatchResult<T> {
  results: (T | undefined)[];
  errors: (Error | undefined)[];
  stats: {
    total: number;
    succeeded: number;
    failed: number;
    processingTimeMs: number;
  };
}
```

### 2. チャンク分割と並列処理 🔵

**信頼性**: 🔵 *dataflow.md バッチ最適化フローより*

アイテムを設定されたチャンクサイズに分割し、設定された並列度で並列処理を実行する。各チャンクの処理結果を元の順序で保持する。

**実装ファイル**: `src/optimization/batch-optimizer.ts`

### 3. フェイルファスト制御 🔵

**信頼性**: 🔵 *要件定義REQ-047より*

failFast=trueの場合、最初のエラーで全処理を即座に中断する。failFast=falseの場合、全チャンクの処理を継続し、成功・失敗を個別に記録する。

**実装ファイル**: `src/optimization/batch-optimizer.ts`

### 4. 進捗コールバックと統計情報 🔵

**信頼性**: 🔵 *要件定義REQ-047・dataflow.mdより*

onProgress コールバックで処理進捗をリアルタイムに通知する。BatchResult の stats に総アイテム数・成功数・失敗数・処理時間を記録する。

**実装ファイル**: `src/optimization/batch-optimizer.ts`
