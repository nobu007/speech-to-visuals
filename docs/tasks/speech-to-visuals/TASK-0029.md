## 実装詳細

### 1. オーバーラップ検出 🔵

**信頼性**: 🔵 *ZERO_OVERLAP_DESIGN.md §3.2 Spatial Hashing, QUALITY_METRICS.md §3.3 より*

全ノードペアのバウンディングボックスの交差を検出する。空間ハッシュ（Spatial Hash）を用いて、O(n^2)の全ペア比較をO(n)に最適化する。動的グリッドサイズをノード分布に基づいて決定し、移動中ノードの差分更新をサポートする。

```typescript
interface SpatialHash {
  insert(node: PositionedNode): void;
  remove(node: PositionedNode): void;
  query(node: PositionedNode): PositionedNode[];
  clear(): void;
}
```

空間ハッシュの実装:
1. 最大ノードサイズを基準にグリッドセルサイズを決定
2. 各ノードを1つ以上のセルに登録
3. 検索時は対象ノードのセルと隣接セルのみ走査
4. 移動時は差分更新でハッシュを維持

**実装ファイル**: `src/visualization/spatial-hash.ts`

### 2. フォースダイレクト法によるオーバーラップ解消 🔵

**信頼性**: 🔵 *ZERO_OVERLAP_DESIGN.md §2.1 Progressive Force-Directed, dataflow.md 機能3 より*

オーバーラップ検出後、フォースダイレクト法でノード位置を調整しオーバーラップを解消する。最大100回の反復制限を設け、収束を監視する。反復ごとにオーバーラップ数を減少させ、進捗がない場合は戦略パラメータを適応的に変更する。

```typescript
interface OverlapResolver {
  resolve(nodes: PositionedNode[], maxIterations: number): PositionedNode[];
  detectOverlaps(nodes: PositionedNode[]): OverlapPair[];
  getOverlapCount(nodes: PositionedNode[]): number;
}
```

フォース計算:
1. 重なり合うノードペア間に反発力を適用
2. 反発力は重なり面積に比例
3. 非重なりノード間は引力で相対位置を維持
4. 適応的ステップサイズで収束を加速

**実装ファイル**: `src/visualization/overlap-resolver.ts`

### 3. 反復回数上限と早期終了 🔵

**信頼性**: 🔵 *ZERO_OVERLAP_DESIGN.md §2.1, QUALITY_METRICS.md §3.3 より*

最大反復回数を100回に制限し、無限ループを防止する。早期終了条件として以下を実装する:
- オーバーラップ数が0になった時点で即座に終了
- 連続5回の反復でオーバーラップ数が変化しない場合は局所最適と判定し終了
- 反復ごとの改善率が閾値以下になった場合は終了

**実装ファイル**: `src/visualization/overlap-resolver.ts`

### 4. 大規模グラフのパフォーマンス最適化 🔵

**信頼性**: 🔵 *ZERO_OVERLAP_DESIGN.md §3.2 Performance Optimizations, QUALITY_METRICS.md §3.3 より*

50ノード以上の大規模グラフでも2秒以内に完了するよう最適化する。

最適化手法:
- 空間ハッシュによるオーバーラップ検出のO(n)化
- バッチ処理によるフォース計算の高速化
- 反復ごとの差分更新による再計算の最小化
- 収束判定の早期実行による無駄な反復の排除

**実装ファイル**: `src/visualization/overlap-resolver.ts`, `src/visualization/spatial-hash.ts`

### 5. オーバーラップ数0の保証 🔵

**信頼性**: 🔵 *ZERO_OVERLAP_DESIGN.md §4.2, QUALITY_METRICS.md §3.3 より*

フォースダイレクト法で100回の反復内にオーバーラップが解消されない場合、Grid-Snap グリッド配置にフォールバックし、オーバーラップ数0を強制的に保証する。この二段構えの方式により、あらゆる入力に対してオーバーラップ0を保証する。

**実装ファイル**: `src/visualization/overlap-resolver.ts`

## 注意事項

- このタスクは NFR-302（レイアウトのオーバーラップ数は常に0）の中核を担う最重要タスクである
- フォースダイレクト法の反復は最大100回とし、必ず終了すること
- 100回で解消できない場合は Grid-Snap フォールバックで強制的にオーバーラップ0を保証すること
- 空間ハッシュは移動ノードの差分更新をサポートすること
- TypeScript strict モードで実装すること
- レイアウト計算は1図解あたり2秒以内（NFR-002）であること
