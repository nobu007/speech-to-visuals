## タスク概要

flow図解タイプのProgress Force戦略を実装する。フロー方向（左→右、上→下）を強調したノード配置を実現し、@dagrejs/dagre 1.1をベースにしたレイアウト計算を行う。フォースダイレクト法で主要な配置を行い、収束しない場合はGrid-Snapフォールバックに切り替える二段構えの方式を採用する。

## 実装詳細

### 1. フロー方向の強調配置 🔵

**信頼性**: 🔵 *ZERO_OVERLAP_DESIGN.md §3.3 Table, dataflow.md 機能3 図解タイプ別戦略テーブル より*

dagreの `g.setGraph({ rankdir: 'LR' })` を使用し、ノードを左から右へフロー方向に配置する。フローの開始ノード（入力エッジなし）を左端に、終了ノード（出力エッジなし）を右端に配置する。中間ノードはトポロジカル順序に従って配置される。

- 主戦略: Progress Force（フロー方向強調付きフォースダイレクト法）
- フォールバック戦略: Grid-Snap
- dagre `rankdir: 'LR'` による階層レイアウト

**実装ファイル**: `src/visualization/strategies/flow-strategy.ts`

### 2. ノード配置計算 🔵

**信頼性**: 🔵 *ZERO_OVERLAP_DESIGN.md §2.1 より*

dagre ライブラリを使用してノードの初期配置を計算する。ノードサイズ（ラベルテキストに基づく幅・高さ）を dagre に渡し、最適なランク（階層）とポジションを決定する。ノード間の最小間隔を設定し、フローの視認性を確保する。

```typescript
// dagre設定例
g.setGraph({
  rankdir: 'LR',
  nodesep: 50,
  ranksep: 80,
  marginx: 40,
  marginy: 40,
});
```

**実装ファイル**: `src/visualization/strategies/flow-strategy.ts`

### 3. エッジパス計算 🔵

**信頼性**: 🔵 *ZERO_OVERLAP_DESIGN.md §2 より*

dagre が算出したエッジポイントを使用して、フロー方向に沿ったエッジパスを生成する。直線・折れ線・曲線のいずれかをフローの密度に応じて自動選択する。エッジラベルの配置位置も計算する。

**実装ファイル**: `src/visualization/strategies/flow-strategy.ts`

### 4. Grid-Snap フォールバック 🔵

**信頼性**: 🔵 *ZERO_OVERLAP_DESIGN.md §2.3, dataflow.md 機能3 より*

Progress Force 戦略でオーバーラップが解消できない場合、Grid-Snap フォールバックに切り替える。フロー方向の順序を維持しつつ、グリッド上にノードを配置してオーバーラップを完全に排除する。

**実装ファイル**: `src/visualization/strategies/flow-strategy.ts`
