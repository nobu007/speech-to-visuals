## 実装詳細

### 1. SimplePipelineInterface コンポーネント実装 🔵

**信頼性**: 🔵 *architecture.md, src/components/SimplePipelineInterface.tsxより*

パイプライン全体を管理するメインコンポーネント。ステートマシンによる状態管理と、各ステージのコンポーネント統合を行う。

- ステートマシン定義:
  - `idle`: 初期状態、ファイルアップロード待ち
  - `uploading`: ファイルアップロード中
  - `transcribing`: 文字起こし処理中
  - `analyzing`: 図解分析中
  - `generating`: 動画生成中
  - `complete`: 動画生成完了
  - `error`: エラー発生
- 状態遷移ロジックの実装
- React Query によるAPI呼び出し管理
- エラー時のロールバック/リトライロジック

**実装ファイル**: `src/components/SimplePipelineInterface.tsx`

### 2. パイプラインステートマシン実装 🔵

**信頼性**: 🔵 *architecture.mdより*

パイプラインの状態遷移を管理するステートマシン。状態遷移の妥当性検証と、現在状態に応じた許可操作の判定を行う。

- 状態遷移の定義と検証
- 不正な遷移の防止
- 状態に応じたコンポーネントの切り替え
- 各状態のコンテキストデータ管理（アップロードID、文字起こし結果等）

**実装ファイル**: `src/components/SimplePipelineInterface.tsx`

### 3. SimplePipeline ページ実装 🔵

**信頼性**: 🔵 *architecture.mdより*

React Router 6.30 を使用したパイプラインページ。URLルーティングとSimplePipelineInterfaceの統合。

- ルート定義: `/pipeline` または `/`
- ページレイアウト（ヘッダー、メインコンテンツ、フッター）
- ナビゲーション
- ページタイトルとメタデータ

**実装ファイル**: `src/pages/SimplePipeline.tsx`

### 4. API通信統合 🔵

**信頼性**: 🔵 *architecture.md, api-endpoints.mdより*

React Query を使用したAPI通信の統合。各パイプラインステージのAPI呼び出しとキャッシュ管理。

- `useMutation` によるAPI呼び出し（アップロード、文字起こし、分析、レンダリング）
- `useQuery` による進捗確認
- WebSocket イベントリスナーによるリアルタイム更新
- エラーハンドリングとリトライロジック

**実装ファイル**: `src/components/SimplePipelineInterface.tsx`

## 注意事項

- React 18.3 の並行レンダリング機能を活用すること（Suspense, useTransition）
- React Query のキャッシュ設定を適切に構成すること（ステール時間、ガベージコレクション時間）
- WebSocket イベントのリスナーはコンポーネントのアンマウント時に適切にクリーンアップすること
- Tailwind CSS + shadcn/ui のデザインシステムに従うこと
- 状態管理はローカルステート（useState/useReducer）で十分。グローバルストアは不要
