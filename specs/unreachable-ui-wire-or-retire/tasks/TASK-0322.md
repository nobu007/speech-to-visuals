## 実装詳細

### 1. Index complete state への mount 🔵

**信頼性**: 🔵 *architecture.md「WIRE 設計 — mount point の決定」節（JSX 形状まで固定）・Index.tsx:227-239 実装より*

**実装ファイル**: `src/pages/Index.tsx`

設計で固定された JSX 形状（`DiagramPreview` と `VideoRenderer` の間・mount 要素は既存要素と同一行に押し込まない）:

```tsx
{result && status === 'complete' && (
  <>
    <DiagramPreview
      scenes={result.scenes}
      onRender={handleRender}
      isRendering={false}
    />
    <VideoPreview
      scenes={result.scenes}
      audioUrl={result.audioUrl}
    />
    <VideoRenderer
      scenes={result.scenes}
      audioUrl={result.audioUrl}
    />
  </>
)}
```

- `VideoPreviewProps`（VideoPreview.tsx:74-85）の必須は `scenes` のみで `audioUrl` は optional — 既存 state の pass-through で済む
- import 文（`VideoPreview` の追加 1 行）も独立行で追加する

### 2. VideoRenderer の死 import 削除 🔵

**信頼性**: 🔵 *architecture.md 裁決 roster #1・REQ-426 (b) より*

**実装ファイル**: `src/components/VideoRenderer.tsx`
