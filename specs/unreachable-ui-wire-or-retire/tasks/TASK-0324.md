## 実装詳細

### 1. 純関数 graph walker 🔵

**信頼性**: 🔵 *architecture.md「到達性 guard 設計」1.・dataflow.md「設計要点」より*

**実装ファイル**: `tests/guards/` 配下に helper として新設（test file と分離した純関数 module — census guard 群の既存構成に従う）

- 入力は `Map<repoRelPath, content>` のみ（fs に触れない・決定論的 — CI 環境差分の影響なし）
- import 辺抽出: `from '…'` / `import('…')` の行走査
- 解決規則: `@/x` → `src/x`・相対 path は解決候補拡張子 `.tsx` / `.ts` / `/index.tsx` / `/index.ts`
- package 外部 import（`react` / `@remotion/player` / `@stv/core/...` 等）は辺を持たない

### 2. guard test 本体 🔵

**信頼性**: 🔵 *architecture.md「到達性 guard 設計」2.〜3.・REQ-425 (e) より*

**実装ファイル**: `tests/guards/component-mount-reachability.test.ts`（新設）

- entry set = `src/main.tsx`（app mount 連鎖の唯一入口）+ `src/remotion/Root.tsx`（Remotion composition 登録 — studio / render tool 経由の別正規入口。React.lazy / barrel file は不存在のため静的走査で完結）

- 実 tree の読み込みは test 側で行い walker は `Map` を受ける（helper は fs 非依存のまま）
