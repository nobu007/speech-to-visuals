## 設計決定

1. **合意率の分母は dataset が決める** — per-type recall は expected-side（当該 human label の case 数が分母）で precision ではない。dataset が各タイプ同数（3）に保たれる限り全体 agreement と per-type recall が同じ土俵に載る。case 追加時は `MIN_CASES_PER_TYPE` と ja/en 1 case 以上の契約が test で強制される。
2. **実測値の下方置換（92% → 84.9%）を許容** — 出典のない高値より出典付きの実測値を正典とする。目標値（>90%）は §3.2 Target として不変で、Current だけが実測に差し替わる。confusion 5 cell は改善課題の実体（rule keyword の過教研が general/comparison で起こっている）として confusion set に可読な形で残す。
3. **baseline pin は ratchet ではなく固定値 exact pin** — 上方向への改善も pin 更新（= 意図的 re-measure + QUALITY_METRICS 再記録）を要求する。test が RED した時点で測定と記録の再実施を強制するのが目的で、自動追従ではない。
