## タスク概要

テスト実行後に「Cannot log after tests are done」警告と「A worker process has failed to exit gracefully」エラーが発生する問題を修正する。原因は `EnhancedErrorRecovery.adjustDynamicCapacity` で設定される `setInterval` タイマーがテスト終了後に解放されていないこと。テストの teardown でタイマーを確実にクリーンアップする。

## 主要実装項目

### 1. EnhancedErrorRecovery タイマークリーンアップ 🔵

**信頼性**: 🔵 *Jest出力より*

`src/quality/enhanced-error-recovery.ts` の `adjustDynamicCapacity` メソッドで使用している `setInterval`（healthCheckInterval: 3000ms）をテスト終了時に確実にクリアする。

**実装ファイル**: `src/quality/enhanced-error-recovery.ts`

### 2. テストの teardown 改善 🔵

**信頼性**: 🔵 *Jest出力より*

`EnhancedErrorRecovery` のテストファイルで `afterEach` / `afterAll` フックでタイマーをクリーンアップする。

**実装ファイル**: `tests/` 内の該当テストファイル

## 注意事項

- `setInterval` は `clearInterval` で解放すること
- クラスに `destroy()` メソッドを追加して全タイマーを解放可能にすること
- テストだけでなく本番利用時のシャットダウン（REQ-050）とも整合させること
