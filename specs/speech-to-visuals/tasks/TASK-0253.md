## 置換パターン（Phase 148/149/165 の fail-loud idiom 踏襲 + 本タスクの拡張）

| パターン | 代表ファイル | ノード |
|---------|---------|-------|
| `find()`/`Map.get()`/`findJob()`/null 戻りの labeled throw guard（冗長な `expect(x).toBeDefined()` を stronger な throw で置換） | timeline-strategy・flowchart-layout-strategy・export-service-shutdown・pipeline.test ほか | ~45 |
| ファイル内 helper（`requireTopology(diagramType)` / `requireNode(nodes, id)` — 欠損 fixture/出力 node を名指し） | force-directed-layout-outcome-oracle・force-directed-simulation | 6 |
| Promise executor / `.catch()` コールバック捕捉変数 → **initializer なし `| undefined` holder** + invocation-time guard | framework-pipeline-unmount（`let resolveExecution: ((value: unknown) => void) \| undefined`）・error-visibility（`let surfacedError: Error \| undefined`） | 8 |
| optional 寸法算術 `n.width! / 2` → `(n.width ?? Number.NaN) / 2`（undefined → NaN → assertion RED 伝播・`!` と truth-table 等価） | canvas-calculator・comparison-layout-strategy・cultural-layout-adapter・overlap-resolver-viz ほか | 21 |
| typed metrics field（`classifiedError?`/`recoveryReport?`）の `result.metrics!.x as T` → `result.metrics?.x` + guard（**不要な cast を削除**） | pipeline-orchestrator-error-classification・recovery-wire-up | 6 |
| `Number.isFinite(x) ? x! : fallback` → `typeof x === 'number' && Number.isFinite(x) ? x : fallback`（型 narrow・同一 truth table） | diagram-video-time-unit-consistency | 3 |
| ILayoutStrategy optional method（`validateInputs!(`/`getStrategyDefaults!()`）→ concrete class 変数から直接呼び出し | comparison/concept-map/network-strategy・v1-strategy-shared-members | 15+ |
| inline `if (m === null) throw`（regex 系 guard の `match(...)!`） | scene-synchronizer-fps ほか guards 全般 | 残り |
| typed fixture interface（`V2CaseEdge extends LayoutEdge` + factory）で `edge.source!` を非 optional 化 | edge-crossing-scan-single-source | — |

**GOTCHA（実測）**: `.catch()` コールバック内で代入される変数の guard は、`let x: Error | null = null` の initializer が CFA 上すべての read を `null` に狭めるため `x === null` throw 後の型が `never` になり TS2339 となる。alias（`const y: Error | null = x`）も initializer による狭化で無効（annotation より initializer が優先）。**正解は initializer を消して `| undefined` holder にする**（fireCapturedResolver と同型）。また typed-errors 5 ファイルの同一 `return classified!` は一括 perl 置換だが、guard の throw 文が helper 化されない粒度は意図（label 付き throw 1 行 = requireDefined 相当）。
