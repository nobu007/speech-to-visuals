## 置換パターン（Phase 167/168 の fail-loud idiom 踏襲）

- **holder は initializer なし + 宣言型に `undefined` を含める**: `= null` initializer は CFA を null 狭化に固定する（TS2339/TS18047）。かと言って initializer なしだけでは宣言型に `undefined` が無いと TS2454（used before assigned）が closure 内 read で発火する。Phase 168 の `.catch()` holder idiom の完結形
- **requireDefined は `T | null | undefined` に widen**: null を捕捉しない `T | undefined` 形は nullable field で型も実行時も穴。他 5 ファイルの同_helper と同じ形に統一
- **census は `import type * as TS from 'typescript'`**: 型のみ静的 import（compile 時に消えるので CJS `typescript` の ESM 読み込みは引き続き createRequire）。型位置 `ts.Node` → `TS.Node`。`isParameter` 分岐は除去し doc comment に「parameter `!:` は TS1005/TS1138 parse error で存在しない」旨を記録
