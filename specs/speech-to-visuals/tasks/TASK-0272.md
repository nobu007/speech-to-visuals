## 背景

`src/framework/recursive-custom-instructions.ts` の Quality Check System は `runQualityChecks` → 4 checkXxxQuality → `evaluateResults` → `passed = overallScore >= 0.8` → `executeDevelopmentCycle` の commit trigger という verdict 経路の中核だが、4 メソッドすべてが測定を 1 つも読まず**定数 fixture** を返していた:

| module | 旧定数 fixture | 測定 source の有無 |
|---|---|---|
| transcription | `accuracy: 0.9, confidence: 0.85, duration: 2.5` | accuracy のみ `metrics.transcriptionAccuracy` に存在 |
| analysis | `sceneSegmentation: 0.82, diagramDetection: 0.78, relationshipExtraction: 0.75` | sceneSegmentation のみ `metrics.sceneSegmentationF1` に存在 |
| visualization | `layoutQuality: 0.95, labelReadability: 1.0, renderPerformance: 0.88` | layoutQuality のみ `metrics.layoutOverlap`（count）から導出可能 |
| integration | `pipelineFlow: 0.93, errorHandling: 0.90, memoryUsage: 0.85` | renderTime / memoryUsage（bytes）のみ測定あり |

影響: (1) overallScore は run 非依存の定数 **≈ 1.0037**（0.8 gate を恒久通過）で、`executeDevelopmentCycle` は implementation() の実際の中身と無関係に毎回 commit — REQ-383 documentation leg / REQ-384 commitPhase と同一の捏造 always-pass verdict class が verdict 経路全体に残存 (2) 秒値 `duration: 2.5` が `calculateModuleScore`（`safeMean(Object.values(...))`）の 0-1 module 平均に混入し module score 1.4167 — 0-1 scale への unit 混入で overallScore が 1.0 を恒久超過 (3) 7 field（confidence / diagramDetection / relationshipExtraction / labelReadability / renderPerformance / pipelineFlow / errorHandling）はこの class 内に測定 source が存在せず、`issues` も定数空配列で extractIssues が常に無情報。

2. **derive 化 fix** — 4 check を `this.currentState.metrics`（recordStageSuccess / recordStageFailure が書き込み・MainPipeline `executeStageWithFramework` が live 駆動・`evaluateIteration` が gate するのと同一 source）からの derive に変更。transcription `accuracy` / analysis `sceneSegmentation` / visualization `layoutQuality`（layoutOverlap count ≤ threshold(0) → 1） / integration `timeBudget` + `memoryBudget`（renderTime / memoryUsage bytes vs threshold・`calculateCurrentQualityScore` と同じ 1|0.5 二値 idiom）。測定 source のない 7 field は再捏造ではなく**削除**（REQ-383 の leg 除去と同型）。`issues` は threshold 違反から derive
