## タスク概要

`safe-storage.ts` の chokepoint は `safeLoadFromStorage` / `safeSaveToStorage`（TC-315 で `safeRemoveFromStorage` 追加済み）が存在するが、内部の `storageParser` は JSON.parse⇔JSON.stringify の方向非対称（parse 時にバリデーションするが stringify 時に再正規化しない可能性）を抱える。本タスクは：

- `safe-storage.ts` の parse / stringify 経路を全列挙し、validator が双方向で適用されているか監査
- 非対称箇所（例: `JSON.parse` 前に validator 適用するが `JSON.stringify` 後に `Date`/`Map`/`undefined` の正規化なし）を特定
- 必要に応じて双方向 validator (`storageParser.serialize` / `storageParser.deserialize`) を構造的に分離し、TC-301 系の guard で pin

直近 steering の「helper 抽出 + docstring」方針と整合：本タスクは guard + mutation witness による検証強化に留め、production code の実 fix は TASK-0220 で扱う。
