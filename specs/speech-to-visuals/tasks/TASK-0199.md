## タスク概要

エクスポートパイプライン全体を end-to-end で検証する統合テストを実装する。
シーンデータ入力から Animated SVG / Lottie JSON / PNG 出力までを一貫してテストし、
既存のユニットテスト（648行の animated-svg-lottie-export 等）では検出できない
モジュール間連携の不具合を捕捉する。

AI Hub フィードバック指摘: 「648行のテストファイルが大きい — integration-level tests exercising the full export pipeline end-to-end would catch issues the current unit tests miss, rather than adding more unit test cases.」

## 主要実装項目

### 1. エクスポートパイプライン E2E テスト基盤 🔵

**信頼性**: 🔵 *enhanced-export-engine.ts, animated-scene-renderer.ts の実装より*

テストファイル `tests/integration/export-pipeline-e2e.test.ts` を作成。
`EnhancedExportEngine` をインスタンス化し、実際のシーンデータ構造を入力として
SVG・Lottie フォーマットのエクスポートを一括実行する。

**テストファイル**: `tests/integration/export-pipeline-e2e.test.ts`

### 2. シーンデータ → SVG E2E 検証 🔵

**信頼性**: 🔵 *REQ-218 実装コミット f405637 より*

3シーン（intro/content/outro）のリアルなシーンデータから SVG エクスポートを実行し、
以下を検証:
- CSS keyframe アニメーションが含まれる
- シーンタイプ別の背景色が正しく適用される
- フェードイン/フェードアウトのタイミングが正しい
- XML エスケープが適用されている

### 3. シーンデータ → Lottie JSON E2E 検証 🔵

**信頼性**: 🔵 *REQ-219 実装コミット 214ec76 より*

同シーンデータから Lottie JSON エクスポートを実行し、以下を検証:
- Lottie 5.7.4 互換構造（v, fr, ip, op, layers フィールド）
- シーンレイヤーにビジュアル形状（rectangle shapes）が含まれる
- 不透明度キーフレームが正しく設定される
- シーンタイプ別色（intro=#1a1a2e, outro=#0f3460, content=#16213e）が正しい

### 4. エラー伝播・フォールバック統合検証 🟡

**信頼性**: 🟡 *既存の error recovery テストパターンからの推測*

不正なシーンデータや空シーンでのエラー伝播を検証:
- 空シーン配列のフォールバック動作
- 不正フォーマット指定時のエラー分類
- 部分的エクスポート失敗時の graceful degradation

## 基本的なテスト要件

### テストケース1: Full SVG pipeline 🔵

**信頼性**: 🔵 *animated-scene-renderer.ts + enhanced-export-engine.ts の実装より*

- Given: 3シーン（intro/content/outro）のリアルなシーンデータ
- When: EnhancedExportEngine 経由で svg-animated フォーマットでエクスポート
- Then: CSS keyframe SVG が生成され、各シーンの背景色・テキスト・タイミングが正しい

### テストケース2: Full Lottie pipeline 🔵

**信頼性**: 🔵 *同上*

- Given: 同一シーンデータ
- When: EnhancedExportEngine 経由で json-lottie フォーマットでエクスポート
- Then: Lottie 5.7.4 構造の JSON が生成され、layers にシーンレイヤーとビジュアル形状が含まれる

### テストケース3: Error propagation 🟡

**信頼性**: 🟡 *既存エラー処理パターンからの推測*

- Given: 空シーン配列または不正データ
- When: エクスポート実行
- Then: フォールバック出力または適切なエラー分類
