## 実装詳細

### 1. LazyLoader コアクラス 🔵

**信頼性**: 🔵 *要件定義REQ-049・src/optimization/lazy-loader.ts・architecture.mdより*

重いモジュールの動的インポートキャッシュを管理する。同時ロード重複排除（同じキーへの同時要求を1回に束ねる）、プリロード、無効化、統計情報を提供する。

**実装ファイル**: `src/optimization/lazy-loader.ts`

```typescript
interface LazyModule<T> {
  module: T;
  loadTimeMs: number;
}

interface LazyLoaderStats {
  totalLoads: number;
  cacheHits: number;
  cacheMisses: number;
  averageLoadTimeMs: number;
  loadedModules: number;
}
```

### 2. 同時ロード重複排除 🔵

**信頼性**: 🔵 *dataflow.md遅延ローダーフローより*

同じキーに対する複数の同時ロード要求を検出し、既存のPromiseを再利用する。これにより、複数コンポーネントから同じモジュールが同時に要求されても1回だけロードが実行される。

**実装ファイル**: `src/optimization/lazy-loader.ts`

### 3. プリロードとハンドルファクトリ 🔵

**信頼性**: 🔵 *dataflow.md遅延ローダーフローより*

preload(key, loader) で非同期にモジュールを事前キャッシュする。エラーは無視され、後続のload()呼び出しで再試行される。createHandle(key, loader) でカプセル化されたハンドルを生成し、handle.load() で随時ロードする。

**実装ファイル**: `src/optimization/lazy-loader.ts`

### 4. 統計情報 🔵

**信頼性**: 🔵 *interfaces.ts LazyLoaderStats型・要件定義REQ-049より*

総ロード回数・キャッシュヒット数・ミス数・平均ロード時間・ロード済みモジュール数を追跡する。パフォーマンス分析とキャッシュ効率の測定に使用する。

**実装ファイル**: `src/optimization/lazy-loader.ts`
