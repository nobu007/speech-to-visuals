## 実装詳細

### 1. キャンバスサイズ計算 🔵

**信頼性**: 🔵 *ZERO_OVERLAP_DESIGN.md §5.1, architecture.md パフォーマンスセクション より*

ノードのバウンディングボックスを計算し、パディングを加えてキャンバスサイズを決定する。基準解像度は1920x1080（REQ-301）とし、ノードが基準サイズに収まる場合はそのまま、収まらない場合はスケーリングする。

```typescript
interface CanvasCalculator {
  calculate(nodes: PositionedNode[]): CanvasSize;
  center(nodes: PositionedNode[], canvas: CanvasSize): PositionedNode[];
}

interface CanvasSize {
  width: number;
  height: number;
  padding: { top: number; right: number; bottom: number; left: number };
  scale: number;
}
```

計算ロジック:
1. 全ノードのバウンディングボックスを算出
2. バウンディングボックスにパディングを追加
3. アスペクト比16:9を維持しつつキャンバスサイズを決定
4. 基準サイズ（1920x1080）を超える場合はスケールダウン

**実装ファイル**: `src/visualization/canvas-calculator.ts`

### 2. センタリング処理 🔵

**信頼性**: 🔵 *ZERO_OVERLAP_DESIGN.md §5.1 より*

レイアウトされたノード群をキャンバスの中央に配置する。ノード群のバウンディングボックスの中心をキャンバスの中心に一致させるよう、全ノードの座標をオフセットする。

```typescript
// センタリング計算
const bbox = calculateBoundingBox(nodes);
const offsetX = (canvas.width - bbox.width) / 2 - bbox.minX;
const offsetY = (canvas.height - bbox.height) / 2 - bbox.minY;
const centeredNodes = nodes.map(node => ({
  ...node,
  x: node.x + offsetX,
  y: node.y + offsetY,
}));
```

**実装ファイル**: `src/visualization/canvas-calculator.ts`

### 3. アスペクト比維持 🔵

**信頼性**: 🔵 *architecture.md パフォーマンスセクション, ZERO_OVERLAP_DESIGN.md §5.1 より*

キャンバスのアスペクト比を16:9に維持する。ノード分布が横長の場合は幅に合わせて高さを調整し、縦長の場合は高さに合わせて幅を調整する。ノード分布のアスペクト比が16:9と大きく異なる場合は、余白を追加して16:9に合わせる。

**実装ファイル**: `src/visualization/canvas-calculator.ts`

### 4. パディング計算 🔵

**信頼性**: 🔵 *ZERO_OVERLAP_DESIGN.md §5.1 より*

ノードとキャンバス端の間に適切なパディングを確保する。パディングはキャンバスサイズの5%を最小値とし、ノードラベルがキャンバス端で切れないことを保証する。パディング量はノードの最大サイズに基づいて動的に調整する。

**実装ファイル**: `src/visualization/canvas-calculator.ts`
