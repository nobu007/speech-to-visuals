## タスク概要

`npm test` 実行時に "A worker process has failed to exit gracefully and has been force exited" 警告が継続して発生している。TASK-0078（Phase 9）およびTASK-0091（Phase 13）で修正を試みたが、完全には解消されていない。テストスイート内のタイマーリーク・未クリーンアップリソースを特定し、警告を完全に解消する。

- [x] `npm test` 実行時にワーカープロセス強制終了警告が表示されない
- [x] `npx jest --detectOpenHandles` でオープンハンドルが検出されない
- [x] 全3,228テストが引き続き通過する

## 主要実装項目

### 1. テストスイートのオープンハンドル特定 🔵

**信頼性**: 🔵 *Jest --detectOpenHandles 出力に基づく*

`npx jest --detectOpenHandles --forceExit` を実行し、オープンハンドルを保持しているテストスイートを特定する。setInterval/setTimeout の未クリーンアップ、イベントリスナーの未削除、モックの不適切な復元が主な原因候補。

**実装ファイル**: `__tests__/` 配下の該当テストファイル

### 2. タイマー・リソースリーク修正 🔵

**信頼性**: 🔵 *TASK-0078/0091 の修正履歴に基づく*

特定されたテストスイートに対して以下を実施：
- `afterAll` / `afterEach` での `clearInterval` / `clearTimeout` 追加
- モックの適切な `mockRestore()` 呼び出し
- イベントエミッターのリスナー削除
- 必要に応じて `jest.useFakeTimers()` の活用

**実装ファイル**: 該当テストファイル
