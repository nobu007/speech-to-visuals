### 1. LayoutAutoOptimizer クラス 🟡

**信頼性**: 🟡 *REQ-083 定義に基づく新規実装*

**実装ファイル**: `src/visualization/layout-auto-optimizer.ts`

```typescript
export interface OptimizationStep {
  iteration: number;
  action: 'reselect_strategy' | 'adjust_params' | 'recalculate';
  previousScore: number;
  newScore: number;
  improved: boolean;
  details: string;
}

export interface OptimizationResult {
  improved: boolean;
  initialScore: number;
  finalScore: number;
  iterations: number;
  steps: OptimizationStep[];
  finalNodes: PositionedNode[];
  finalEdges: LayoutEdge[];
}

export class LayoutAutoOptimizer {
  constructor(
    compositeScorer: LayoutQualityCompositeScorer,
    strategySelector: StrategySelector,
    maxIterations?: number  // 既定: 3
  );

  async optimize(
    nodes: PositionedNode[],
    edges: LayoutEdge[],
    diagramType: DiagramType,
    bounds: { width: number; height: number }
  ): Promise<OptimizationResult>;
}
```

### 2. 戦略再選択 🔵

**信頼性**: 🔵 *既存 StrategySelector の活用*

現在の戦略が低スコアの場合、フォールバックチェーンの次戦略を試行。例: DagreLayoutStrategy → FallbackLayoutStrategy。

### 3. パラメータ調整 🟡

**信頼性**: 🟡 *REQ-083 の概念*

バランスが低い → nodeSpacing/rankSeparation を増加
交差が多い → エッジ重み付けを調整
あふれあり → ノードサイズを拡大

### 4. 再計算ループ 🟡

**信頼性**: 🟡 *AutoImprovementEngine のパターンに準拠*

1. 初回スコア評価
2. スコア < 閾値 → 最適化アクション実行
3. 再計算 → スコア再評価
4. 改善なし or 最大反復到達 → 終了
