## 概要

音声ファイルの文字起こし前にオーディオ前処理ステージを実装する。無音区間検出（発話開始/終了の自動検出）・ノイズレベル推定（SN比に基づく品質評価）・音声長バリデーション（1秒未満の拒否・1時間超の警告）を実施する。

## 実装内容

1. `src/transcription/audio-preprocessor.ts` 新規実装
   - Web Audio API を用いたオフラインオーディオ分析
   - 無音区間検出（RMSエネルギー閾値ベース）
   - ノイズレベル推定（SN比計算）
   - 音声長バリデーション（REQ-001: 1秒未満拒否・EDGE-103: 1時間超警告）
2. パイプラインオーケストレーター Stage 0（前処理）への統合
3. テスト: `tests/transcription/audio-preprocessor.test.ts`

## 受け入れ基準

- [x] 音声ファイルの無音区間が検出され、発話区間のみが文字起こしに渡される
- [x] ノイズレベルが推定され、SN比が品質メトリクスに記録される
- [x] 1秒未満の音声は拒否され、適切なエラーメッセージが返される
- [x] 1時間を超える音声は警告付きで処理が継続される
- [x] ユニットテストが全て通過する（最低15テストケース）
- [x] TypeScript型エラー0件・ESLintエラー0件を維持
