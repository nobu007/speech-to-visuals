## 実装詳細

### 1. Remotion プロジェクト構造設定 🔵

**信頼性**: 🔵 *architecture.mdより*

Remotion 4.0 をプロジェクトに統合し、必要な依存パッケージをインストールする。Vite 5.4 との統合設定を行う。

- `@remotion/cli` 4.0
- `@remotion/player` 4.0
- `remotion` 4.0
- `@remotion/vite-plugin`

**実装ファイル**: `remotion.config.ts`

### 2. ルートコンポーネント実装 🔵

**信頼性**: 🔵 *architecture.md, note.mdより*

Remotionのエントリーポイントとなるルートコンポーネントを実装する。Compositionの登録とメタデータの設定を行う。

- `Root.tsx`: Remotionのエントリーポイント。Composition登録、メタデータ定義
- デフォルト解像度: 1920x1080 (1080p)
- デフォルトFPS: 30
- 動画の総フレーム数計算ロジック

**実装ファイル**: `src/remotion/Root.tsx`

### 3. Video コンポーネント実装 🔵

**信頼性**: 🔵 *architecture.mdより*

メインの動画コンポーネント。シーンの切り替え、トランジション、全体のタイムライン管理を担当する。

- シーン配列を受け取り、フレームに応じて適切なシーンをレンダリング
- シーン間のトランジション処理
- `useCurrentFrame()` と `useVideoConfig()` の活用

**実装ファイル**: `src/remotion/Video.tsx`

### 4. Composition 定義 🔵

**信頼性**: 🔵 *architecture.mdより*

RemotionのComposition定義。標準設定として1080p 30fpsをデフォルトとし、将来的な設定変更に対応できる構造にする。

```typescript
// Composition設定例
const VideoComposition: React.FC = () => {
  return (
    <Composition
      id="SpeechToVisualsVideo"
      component={Video}
      durationInFrames={calculateTotalFrames(scenes)}
      fps={30}
      width={1920}
      height={1080}
      defaultProps={defaultVideoProps}
    />
  );
};
```

**実装ファイル**: `src/remotion/Root.tsx`
