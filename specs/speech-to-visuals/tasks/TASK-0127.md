## 主要実装項目

### 1. LayoutQualityCompositeScorer クラス 🟡

**信頼性**: 🟡 *REQ-082 定義に基づく新規実装*

**実装ファイル**: `src/visualization/layout-quality-composite.ts`

```typescript
export interface CompositeQualityWeights {
  balance: number;     // バランススコア重み（既定: 0.3）
  crossing: number;    // 交差スコア重み（既定: 0.3）
  overflow: number;    // あふれスコア重み（既定: 0.2）
  density: number;     // 密度スコア重み（既定: 0.2）
}

export interface CompositeQualityResult {
  compositeScore: number;        // 0.0~1.0 統合スコア
  balanceScore: number;          // TASK-0124 の結果
  crossingScore: number;         // TASK-0125 の結果（1 - crossings/maxCrossings）
  overflowScore: number;         // TASK-0126 の結果
  densityScore: number;          // 密度均一性スコア
  passed: boolean;               // compositeScore >= threshold
  details: string;               // 人間可読な詳細
}

export class LayoutQualityCompositeScorer {
  constructor(weights?: Partial<CompositeQualityWeights>, threshold?: number);

  evaluate(
    nodes: PositionedNode[],
    edges: LayoutEdge[],
    bounds: { width: number; height: number },
    diagramType: DiagramType
  ): CompositeQualityResult;

  getThreshold(): number;
}
```

### 2. 交差スコア正規化 🟡

**信頼性**: 🟡 *交差数→スコアの変換*

エッジ交差数を0.0~1.0に正規化。最大交差数はエッジ総数の組み合わせ nC2 を上限とし、交差0で1.0、最大交差で0.0。

### 3. 品質ゲート統合 🔵

**信頼性**: 🔵 *既存 quality-gate.ts のパターンに準拠*

Stage 3（レイアウト品質）に複合品質スコア基準を追加。閾値0.7未満はブロック。

## 基本的なテスト要件

### 複合スコア計算テスト 🔵

**信頼性**: 🔵 *重み付き平均のテスト*

- 全指標1.0 → compositeScore = 1.0
- 全指標0.5 → compositeScore = 0.5
- 一部指標低 → 該当重み分だけ低下

### 閾値テスト 🔵

**信頼性**: 🔵 *閾値判定のテスト*

- compositeScore ≥ 0.7 → passed = true
- compositeScore < 0.7 → passed = false

### 品質ゲート統合テスト 🟡

**信頼性**: 🟡 *既存品質ゲートとの統合テスト*

- 複合スコア基準がStage 3に正しく追加される
- 既存の zeroOverlap 基準と共存
