## タスク概要

timeline図解タイプのレイアウト戦略を実装する。Y軸を時間軸として固定し、時系列の順序を明確に表現する。ノードのY座標はタイムスタンプに基づいて決定し、X座標はフォースダイレクト法で最適化する。収束しない場合はGrid-Snapフォールバックに切り替える。

## 実装詳細

### 1. Y軸固定の時系列配置 🔵

**信頼性**: 🔵 *ZERO_OVERLAP_DESIGN.md §3.3 Table, dataflow.md 機能3 図解タイプ別戦略テーブル より*

ノードのY座標をタイムスタンプに基づいて固定配置する。最も早いタイムスタンプのノードを最上位（Y=0に近い）に配置し、時間が進むにつれて下方向に配置する。ノード間の最小Y間隔を保証し、タイムスタンプが近いノードでも重ならないようにする。

- 主戦略: Force（X制約付きフォースダイレクト法）
- フォールバック戦略: Grid-Snap
- Y軸: タイムスタンプに基づく固定配置

**実装ファイル**: `src/visualization/strategies/timeline-strategy.ts`

### 2. X軸の最適配置 🔵

**信頼性**: 🔵 *ZERO_OVERLAP_DESIGN.md §2.1 より*

Y座標が固定された状態で、X座標のみフォースダイレクト法で最適化する。Y軸方向の力を無効化し、X軸方向のみ反発力を適用する。同じY位置付近のノード同士が水平方向に分散するよう、制約付きフォース計算を実行する。

```typescript
// X軸のみフォース適用
// Y軸はタイムスタンプに基づく固定値
const fixedY = timestampToY(node.timestamp, minY, maxY, canvasHeight);
const optimizedX = forceDirectedX(node, otherNodes, fixedY);
```

**実装ファイル**: `src/visualization/strategies/timeline-strategy.ts`

### 3. タイムスタンプ変換 🔵

**信頼性**: 🔵 *dataflow.md 機能3 より*

ノードのタイムスタンプをY座標に変換するマッピング関数を実装する。最小タイムスタンプをY=paddingに、最大タイムスタンプをY=canvasHeight-paddingにマッピングする。等間隔配置と実際のタイムスタンプ比率配置の両方をサポートする。

**実装ファイル**: `src/visualization/strategies/timeline-strategy.ts`

### 4. Grid-Snap フォールバック 🔵

**信頼性**: 🔵 *ZERO_OVERLAP_DESIGN.md §2.3 より*

X制約フォース戦略でオーバーラップが解消できない場合、Grid-Snap フォールバックに切り替える。Y座標（時系列順序）は維持し、X座標のみグリッドにスナップする。時間軸の順序が崩れないことを保証する。

**実装ファイル**: `src/visualization/strategies/timeline-strategy.ts`
