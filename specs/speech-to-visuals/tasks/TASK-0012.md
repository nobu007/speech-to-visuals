## 実装詳細

### 1. SpeechRecognition API ラッパー 🔵

**信頼性**: 🔵 *src/transcription/browser-transcriber.ts, SYSTEM_CORE.md より*

Web Speech APIのSpeechRecognitionをラップするBrowserTranscriberクラスを実装する。

- `BrowserTranscriber` クラス: SpeechRecognition APIのライフサイクル管理
- `start()`: 音声認識の開始。連続認識モード（continuous: true）で起動
- `stop()`: 音声認識の停止。最終結果を返す
- `pause()`: 音声認識の一時停止
- `resume()`: 音声認識の再開
- `onInterimResult(callback)`: 中間結果ストリーミングコールバックの登録
- `onFinalResult(callback)`: 最終結果コールバックの登録
- `onError(callback)`: エラーコールバックの登録
- `getState()`: 現在の認識状態（idle/listening/paused/error）を返す

**実装ファイル**: `src/transcription/browser-transcriber.ts`

### 2. ブラウザ互換性チェック 🔵

**信頼性**: 🔵 *SYSTEM_CORE.md §3 より*

ブラウザがWeb Speech APIをサポートしているか検出する。

- `isSupported()`: SpeechRecognition API（webkitSpeechRecognition含む）の存在確認
- `getBrowserCompatibility()`: ブラウザ名とサポート状況を返す
- Chrome/Edge: フルサポート
- Firefox/Safari: 非サポート（警告表示）

**実装ファイル**: `src/transcription/browser-transcriber.ts`

### 3. イベントハンドリングとエラー処理 🔵

**信頼性**: 🔵 *SYSTEM_CORE.md §3, requirements.md REQ-002 より*

SpeechRecognitionイベントのハンドリングとエラー処理を実装する。

- `onresult` イベント: 中間結果（isFinal: false）と最終結果（isFinal: true）の振り分け
- `onerror` イベント: no-speech, audio-capture, not-allowed, network エラーのハンドリング
- `onend` イベント: 自動再起動（連続認識維持）とクリーンアップ
- タイムアウト処理: 無音状態が30秒続いた場合の自動停止
- エラー復旧: 一時的エラー（network）の自動リトライ

**実装ファイル**: `src/transcription/browser-transcriber.ts`

## 単体テスト要件

### テストケース1: 音声認識開始・停止テスト 🔵

**Given**: BrowserTranscriberインスタンスが作成されている。ブラウザがWeb Speech APIをサポートしている
**When**: `start()` を呼び出し、その後 `stop()` を呼び出す
**Then**: 状態が idle → listening → idle に遷移する。SpeechRecognitionのstart/stopが呼ばれる

**テストファイル**: `src/transcription/__tests__/browser-transcriber.test.ts`

### テストケース2: 中間結果コールバックテスト 🔵

**Given**: BrowserTranscriberが開始状態（listening）。onInterimResultコールバックが登録されている
**When**: SpeechRecognitionが中間結果（isFinal: false）を発火する
**Then**: 登録されたコールバックが中間テキストで呼び出される

**テストファイル**: `src/transcription/__tests__/browser-transcriber.test.ts`

### テストケース3: ブラウザ互換性チェックテスト 🔵

**テストファイル**: `src/transcription/__tests__/browser-transcriber.test.ts`

**Given**: BrowserTranscriberが開始状態（listening）

## 注意事項

- Web Speech APIはブラウザ固有の実装差異があるため、webkitSpeechRecognitionフォールバックを必ず実装すること
- SpeechRecognitionのモック化はテストファイル内で行い、実際のブラウザAPIに依存しないテストにすること
- 連続認識モード（continuous: true）でonendイベント後に自動再起動する際、無限ループに注意すること
- マイクアクセス許可（getUserMedia）は別タスクで管理される前提とする
- TypeScript型定義は TASK-0002 で定義された型を使用すること
