## 実装詳細

### 1. EnhancedFileUploader コンポーネント実装 🔵

**信頼性**: 🔵 *src/components/EnhancedFileUploader.tsx, architecture.mdより*

ドラッグ＆ドロップとクリック選択に対応したファイルアップロードコンポーネント。shadcn/uiのButton, Card コンポーネントをベースに実装する。

- ドラッグ＆ドロップゾーンのUI
- クリックによるファイル選択（非表示input[type="file"]）
- ドラッグオーバー時のビジュアルフィードバック
- ドロップ時のファイル受取処理
- 複数ファイルの防止（単一ファイルのみ）

**実装ファイル**: `src/components/EnhancedFileUploader.tsx`

### 2. ファイル検証ロジック実装 🔵

**信頼性**: 🔵 *src/components/EnhancedFileUploader.tsx, EDGE-101より*

クライアントサイドでのファイル形式・サイズ検証。

- 対応形式: MP3 (audio/mpeg), WAV (audio/wav), OGG (audio/ogg), M4A (audio/mp4, audio/x-m4a)
- ファイルサイズ上限: 50MB (52,428,800 bytes)
- MIMEタイプと拡張子の両方をチェック
- 空ファイルの検出

**実装ファイル**: `src/components/EnhancedFileUploader.tsx`

### 3. アップロード進捗表示 🔵

**信頼性**: 🔵 *architecture.mdより*

ファイルアップロードの進捗をプログレスバーで表示する。

- shadcn/ui Progress コンポーネントの使用
- アップロード割合の表示
- アップロード完了/失敗のステータス表示
- XMLHttpRequest または fetch + ReadableStream による進捗取得

**実装ファイル**: `src/components/EnhancedFileUploader.tsx`

### 4. エラーハンドリング 🔵

**信頼性**: 🔵 *EDGE-101より*

ファイルアップロードに関連するエラーのハンドリングと表示。

- 不対応形式のエラーメッセージ
- サイズ超過のエラーメッセージ
- ネットワークエラーのエラーメッセージ
- エラー状態からの復帰（再選択可能にする）

**実装ファイル**: `src/components/EnhancedFileUploader.tsx`

## 注意事項

- HTML5 Drag and Drop APIを使用するが、モバイルブラウザでの互換性に注意すること
- ファイルのMIMEタイプはブラウザによって検出方法が異なる場合がある。拡張子との併用チェックを推奨
- 50MBの制限はクライアントサイドとサーバーサイドの両方で検証すること
- React 18.3 の `useCallback` を使用してイベントハンドラーをメモ化し、不要な再レンダリングを防止すること
