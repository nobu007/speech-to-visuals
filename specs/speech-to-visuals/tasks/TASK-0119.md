## 主要実装項目

### 1. export-delegation-helpers.test.ts の型修正（27エラー） 🔵

**信頼性**: 🔵 *npm run lint出力・ソースファイル直接確認より*

以下の型置換が必要:

- `createEngineWithPool(poolMock: any)` → `createEngineWithPool(poolMock: WorkerPool | null)`
- `makePoolMock(executeReturn: any): any` → 適切な`WorkerResponse<ExportWorkerResult>`型を使用
- `createJob(overrides): any` → 適切なジョブ型インターフェースを定義
- `as any`型アサーション → 適切なunion型・literal型を使用（fps, resolution等）

**実装ファイル**: `src/workers/__tests__/export-delegation-helpers.test.ts`

### 2. layout-delegation-helpers.test.ts の型修正（19エラー） 🔵

**信頼性**: 🔵 *npm run lint出力・ソースファイル直接確認より*

以下の型置換が必要:

- `(_config?: any, _fallback?: any)` → `(_config?: LayoutConfig, _fallback?: FallbackLayoutStrategy)`
- `createEngineWithPool(poolMock: any)` → `createEngineWithPool(poolMock: WorkerPool | null)`
- `makePoolMock(response: any): any` → `WorkerResponse<LayoutWorkerResult>`型を使用
- プライベートメソッドアクセスの`(engine as any)` → テスト用ユーティリティ抽出または適切な型キャスト

**実装ファイル**: `src/workers/__tests__/layout-delegation-helpers.test.ts`

### 3. export-engine-integration.test.ts の型修正（1エラー） 🔵

**信頼性**: 🔵 *npm run lint出力より*

**実装ファイル**: `src/workers/__tests__/export-engine-integration.test.ts`

### 4. layout-engine-integration.test.ts の型修正（4エラー） 🔵

**信頼性**: 🔵 *npm run lint出力より*

- `(_config?: any, _fallback?: any)` → `(_config?: LayoutConfig, _fallback?: FallbackLayoutStrategy)`
