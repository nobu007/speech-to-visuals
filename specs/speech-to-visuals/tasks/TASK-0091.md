## タスク概要

テスト実行後にJestワーカープロセスが正常終了せず、警告が発生している。`--detectOpenHandles` で確認すると、テストのティアダウン不足によるオープンハンドル（タイマー・イベントリスナー・コネクション等）が残存している可能性がある。テストスイートのクリーンな終了を確保する。

## 依存タスク

- **前提タスク**: [TASK-0078](TASK-0078.md)（前回のタイマーリーク修正）
- **後続タスク**: [TASK-0093](TASK-0093.md)

## 完了条件

- [ ] `npm test 2>&1` にワーカープロセス強制終了の警告が含まれないこと
- [ ] `npm test -- --detectOpenHandles 2>&1` でオープンハンドルが0件であること
- [ ] 全テストが通過すること
- [ ] テスト実行後にプロセスが正常終了すること（exit code 0）

---

## 主要実装項目

### 1. オープンハンドルの特定 🔵

**信頼性**: 🔵 *Jest --detectOpenHandles 出力より*

`npm test -- --detectOpenHandles --forceExit` を実行し、残存するオープンハンドルの種類と発生箇所を特定する。

### 2. テストティアダウンの修正 🔵

**信頼性**: 🔵 *Jest ベストプラクティスより*

特定されたオープンハンドルに対応:
- 未クリアのタイマー（setTimeout/setInterval）の afterAll での清除
- イベントリスナーの removeListener
- モックの restoreAllMocks
- コネクション・ストリームの適切なクローズ

**実装ファイル**: 該当するテストファイル群

---
