## タスク概要

31テストファイルで `jest.resetModules()`、`jest.clearModules()`、`jest.restoreAllMocks()` の呼び出しがESM（ECMAScript Modules）環境で `ReferenceError: jest is not defined` エラーを発生する問題を修正する。`@jest/globals` からの明示的インポートまたは代替パターンに置換する。

### 2. ESM互換テストパターンの適用 🔵

**信頼性**: 🔵 *complexity-detector.test.ts で実際に失敗パターンを確認済*

各ファイルで以下の修正を実施:
1. `import { jest, describe, test, expect, beforeEach, afterEach } from '@jest/globals'` を追加
2. グローバル `jest` 参照をインポート済みの `jest` に置換
3. `jest.resetModules()` が必要な場合は `jest.isolateModules()` または `jest.replaceProperty()` などの代替を使用
