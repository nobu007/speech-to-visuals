## 概要

ストリーミング文字起こしパイプライン（StreamingProcessor + streaming-transcriber）において、各チャンクの文字起こし品質を QualityMonitor でリアルタイムに評価する機能を実装する。現在ストリーミングパイプラインは品質ゲートをバイパスしており、文字起こし品質が監視されていない。

## 実装内容

1. `src/transcription/streaming-transcriber.ts` に QualityMonitor 統合
   - 各チャンクの文字起こし信頼度スコアを記録
   - 品質低下検出時にコールバックで UI に通知
2. `src/components/StreamingProcessor.tsx` に品質インジケーター追加
   - リアルタイム品質スコア表示
   - 品質低下警告バナー
3. テスト: `tests/transcription/streaming-quality-monitor.test.ts`

## 受け入れ基準

- [x] ストリーミング文字起こしで各チャンクの品質スコアが QualityMonitor に記録される
- [x] 品質スコアが閾値を下回った場合にユーザーに警告が表示される
- [x] 品質メトリクスがストリーミング完了時にパイプラインメトリクスに集約される
