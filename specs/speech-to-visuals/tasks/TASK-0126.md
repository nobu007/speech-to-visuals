### 1. SmartLabelSizer クラス 🟡

**信頼性**: 🟡 *REQ-081 定義に基づく新規実装*

**実装ファイル**: `src/visualization/smart-label-sizer.ts`

```typescript
export interface LabelSizingResult {
  fontSize: number;           // 計算後フォントサイズ(px)
  lineHeight: number;         // 行の高さ(px)
  lines: string[];            // 折り返し後の行配列
  isTruncated: boolean;       // 省略されたか
  overflowScore: number;      // 0.0~1.0 あふれスコア（1.0=完全に収まる）
  maxWidth: number;           // 利用可能最大幅
  maxHeight: number;          // 利用可能最大高
}

export interface LabelSizingConfig {
  minFontSize: number;        // 最小フォントサイズ（既定: 10）
  maxFontSize: number;        // 最大フォントサイズ（既定: 16）
  baseFontSize: number;       // 基準フォントサイズ（既定: 14）
  charWidthRatio: number;     // 文字幅比率（既定: 0.6）
  paddingX: number;           // 水平パディング（既定: 8）
  paddingY: number;           // 垂直パディング（既定: 4）
  maxLines: number;           // 最大行数（既定: 3）
  ellipsis: string;           // 省略記号（既定: '...'）
}

export class SmartLabelSizer {
  constructor(config?: Partial<LabelSizingConfig>);

  sizeLabel(
    text: string,
    nodeWidth: number,
    nodeHeight: number
  ): LabelSizingResult;

  detectOverflow(
    text: string,
    nodeWidth: number,
    nodeHeight: number,
    fontSize: number
  ): boolean;

  wrapText(text: string, maxWidth: number, fontSize: number): string[];

  truncateText(text: string, maxWidth: number, fontSize: number): string;
}
```

### 2. フォントサイズ自動計算 🔵

**信頼性**: 🔵 *テキストレンダリングの標準的手法*

テキスト長とノード幅から最適フォントサイズを逆算。テキストが短い→大きいフォント、長い→小さいフォント。最小フォントサイズを下回る場合は行折り返しに移行。

### 3. 行折り返し 🔵

**信頼性**: 🔵 *テキストレイアウトの標準的手法*

文字幅推定に基づいて単語/文字単位で折り返し位置を決定。日本語は文字単位、英語は単語単位での折り返しをサポート。

### 4. 省略表示 🔵

**信頼性**: 🔵 *標準的な省略表示ロジック*

最大行数を超過するテキストを省略記号付きで切り詰め。

## 基本的なテスト要件

### フォントサイズ計算テスト 🔵

**信頼性**: 🔵 *確定的計算のテスト*

- 短いラベル（3文字）→ maxFontSize
- 長いラベル（50文字）→ minFontSize または折り返し
- 空文字列 → デフォルトサイズ

### 折り返しテスト 🔵

**信頼性**: 🔵 *標準ロジックのテスト*

- 1行に収まるテキスト → 1行のまま
- 幅を超えるテキスト → 複数行に分割
- maxLines超過 → 省略表示

### あふれ検出テスト 🟡

**信頼性**: 🟡 *新規ロジックのテスト*

- テキストがノード内に収まる → overflowScore ≈ 1.0
- テキストがあふれる → overflowScore < 1.0
