## タスク概要

基本5タイプ（flow, tree, timeline, matrix, cycle）を超える6つの拡張ダイアグラムタイプ（flowchart, comparison, network, conceptmap, mindmap, general）に対応する専用レイアウト戦略を実装する。各タイプに最適化された配置アルゴリズムを提供し、既存のLayoutStrategyインターフェースに準拠する。

- **前提タスク**: [TASK-0023: レイアウトエンジンコア](TASK-0023.md), [TASK-0031: レイアウト戦略自動選択](TASK-0031.md)
- **後続タスク**: [TASK-0062: 高度レイアウトエンジン](TASK-0062.md)

- [ ] ComparisonLayoutStrategy: 2列縦分割、項目比較表示
- [ ] NetworkLayoutStrategy: 3相力指向（初期配置→クラスタ→微調整）

## 実装詳細

### 1. FlowchartLayoutStrategy 🔵

**信頼性**: 🔵 *設計文書 architecture.md および実装 FlowchartLayoutStrategy.ts より*

Dagreベースのフローチャート専用レイアウト戦略。TB（上→下）方向の階層配置。

**実装ファイル**: `src/visualization/strategies/FlowchartLayoutStrategy.ts`

- rankdir: 'TB' でDagreによる段階的配置
- フロー段階（start/process/decision/end）ごとの最適化
- エッジ交差最小化
- フォールバック: FallbackLayoutStrategy

### 2. ComparisonLayoutStrategy 🔵

**信頼性**: 🔵 *設計文書 architecture.md および実装 ComparisonLayoutStrategy.ts より*

2列縦分割による比較図専用レイアウト。

**実装ファイル**: `src/visualization/strategies/ComparisonLayoutStrategy.ts`

- 左右2列の均等分割
- 対応項目の水平アライメント
- 差異ハイライト配置
- フォールバック: FallbackLayoutStrategy

### 3. NetworkLayoutStrategy 🔵

**信頼性**: 🔵 *設計文書 architecture.md および実装 NetworkLayoutStrategy.ts より*

ネットワーク図専用の3相力指向レイアウト。

**実装ファイル**: `src/visualization/strategies/NetworkLayoutStrategy.ts`

- Phase 1: ランダム初期配置
- Phase 2: コミュニティ検出クラスタリング
- Phase 3: 力指向微調整
- エッジ交差最小化
- フォールバック: FallbackLayoutStrategy

### 4. ConceptMapLayoutStrategy 🔵

**信頼性**: 🔵 *設計文書 architecture.md および実装 ConceptMapLayoutStrategy.ts より*

概念マップ、マインドマップ、汎用図のグリッドベースレイアウト。

**実装ファイル**: `src/visualization/strategies/ConceptMapLayoutStrategy.ts`

- グリッド配置アルゴリズム
- conceptmap/mindmap/general 3タイプ対応
- ノード密度に応じたグリッドサイズ自動計算
- フォールバック: FallbackLayoutStrategy

### 5. StrategyRegistry統合 🔵

**信頼性**: 🔵 *実装 base-strategy.ts DefaultStrategyRegistry より*

拡張6タイプをStrategyRegistryに登録。

**実装ファイル**: `src/visualization/strategies/base-strategy.ts`

- ダイアグラムタイプ → 戦略マッピング
- フォールバックチェーン設定
- 複雑度推定ロジック
