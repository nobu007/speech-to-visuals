## 実装詳細

### 1. ExportArtifactStore 🔵

**信頼性**: 🔵 *既存 MultiFormatExporter・ProductionExporter 成果物管理要件より*

エクスポート成果物をメタデータ付きで管理するストアクラスを実装する。成果物は一意のartifactIdで識別し、フォーマット・サイズ・作成日時・TTL・ダウンロード回数などのメタデータを保持する。インメモリストア（Map）で実装し、将来的な外部ストレージ（S3等）への拡張を考慮したインターフェース設計にする。

**実装ファイル**: `src/export/export-artifact-store.ts`

```typescript
// 型定義
export interface ExportArtifact {
  artifactId: string;
  jobId: string;
  format: string;
  data: ArrayBuffer | string;
  size: number;
  createdAt: number;
  expiresAt: number;
  downloadCount: number;
  lastDownloadedAt?: number;
  metadata: Record<string, unknown>;
}

export interface ArtifactStoreOptions {
  defaultTtl: number;          // デフォルト: 3600000ms (1時間)
  maxStorageBytes: number;     // デフォルト: 1073741824 (1GB)
  maxArtifacts: number;        // デフォルト: 1000
  cleanupInterval: number;     // デフォルト: 60000ms (1分)
}

// ExportArtifactStore クラス
export class ExportArtifactStore {
  private artifacts: Map<string, ExportArtifact>;
  private totalBytes: number;
  private cleanupTimer?: ReturnType<typeof setInterval>;
  private readonly options: ArtifactStoreOptions;

  constructor(options?: Partial<ArtifactStoreOptions>);

  store(jobId: string, format: string, data: ArrayBuffer | string, metadata?: Record<string, unknown>): ExportArtifact;
  retrieve(artifactId: string): ExportArtifact | undefined;
  delete(artifactId: string): boolean;
  generateDownloadUrl(artifactId: string, ttl?: number): string | undefined;
  getStorageUsage(): StorageUsage;
  getArtifactStats(): ArtifactStats;
  cleanupExpired(): number;
  startAutoCleanup(): void;
  stopAutoCleanup(): void;
  clear(): void;
}
```

### 2. TTLベース自動クリーンアップ 🔵

**信頼性**: 🔵 *一般的なキャッシュTTLパターン・src/optimization/intelligent-cache.ts のLRU設計より*

定期的に期限切れアーティファクトをクリーンアップする。cleanupInterval（デフォルト1分）ごとにexpiresAtが現在時刻を過ぎたアーティファクトを削除する。ストレージ使用量がmaxStorageBytesを超えた場合は、最も古いアーティファクトから優先的に削除する（LRU）。

**実装ファイル**: `src/export/export-artifact-store.ts`

### 3. ダウンロードURL生成 🔵

**信頼性**: 🔵 *一般的な署名付きURL パターンより*

アーティファクトへのダウンロードURLを生成する。URLにはartifactIdと有効期限（デフォルト5分）を含める。URLは内部的にはartifactIdへのマッピングとして扱い、期限切れ後はアクセス不可とする。将来的な署名付きURL（HMAC等）への拡張を考慮したインターフェース。

**実装ファイル**: `src/export/export-artifact-store.ts`

### 4. 使用量追跡とクォータ管理 🔵

**信頼性**: 🔵 *src/config/limits.ts の設定集約パターン・SYSTEM_CONSTITUTION制限値管理より*

ストレージ使用量をリアルタイムで追跡する。総バイト数・アーティファクト数・フォーマット別分布を提供する。maxStorageBytesとmaxArtifactsのクォータに達した場合、新規保存前に古いアーティファクトを退去させる。ARTIFACT_LIMITS 定数を src/config/limits.ts に集約する。

**実装ファイル**: `src/export/export-artifact-store.ts`、`src/config/limits.ts`

### 5. ExportMetricsCollector 統合 🔵

**信頼性**: 🔵 *REQ-226 ExportMetricsCollector 設計より*

ExportArtifactStore のイベントを ExportMetricsCollector に統合する。artifact_stored_count、artifact_storage_bytes、artifact_expired_count、artifact_download_count の4メトリクスを追加する。

**実装ファイル**: `src/export/export-artifact-store.ts`、`src/export/export-metrics-collector.ts`
