## 実装詳細

### 1. ExportJobQueue 優先度スケジューリング 🔵

**信頼性**: 🔵 *既存 enhanced-export-engine.ts・production-exporter.ts 設計より*

優先度付きジョブキューを実装する。ジョブは3段階の優先度（high/normal/low）を持つ。ユーザー手動操作はhigh、バッチ処理はnormal、自動生成はlowに割り当てる。優先度が同じ場合はFIFOで処理する。

**実装ファイル**: `src/export/export-job-queue.ts`

```typescript
// 型定義
export type JobPriority = 'high' | 'normal' | 'low';

export interface QueuedExportJob {
  jobId: string;
  priority: JobPriority;
  enqueuedAt: number;
  startedAt?: number;
  completedAt?: number;
  status: 'queued' | 'running' | 'completed' | 'failed' | 'cancelled';
  format: string;
  inputHash: string;
}

export interface ExportJobQueueOptions {
  maxConcurrent: number;         // デフォルト: 3
  maxQueueSize: number;          // デフォルト: 100
  starvationPreventionInterval: number; // デフォルト: 30000ms
}

// ExportJobQueue クラス
export class ExportJobQueue {
  private queue: QueuedExportJob[];
  private running: Map<string, QueuedExportJob>;
  private readonly options: ExportJobQueueOptions;

  constructor(options?: Partial<ExportJobQueueOptions>);

  enqueue(job: Omit<QueuedExportJob, 'jobId' | 'enqueuedAt' | 'status'>): QueuedExportJob;
  dequeue(): QueuedExportJob | undefined;
  cancel(jobId: string): boolean;
  getQueuePosition(jobId: string): number | undefined;
  getEstimatedWaitTime(jobId: string): number;
  getQueueStats(): QueueStats;
  processNext(): Promise<void>;
  start(): void;
  stop(): void;
}
```

### 2. 同時実行制御 🔵

**信頼性**: 🔵 *既存 BatchOptimizer セマフォパターン・BATCH_LIMITS.MAX_CONCURRENT_JOBS より*

セマフォパターンで同時実行数を制御する。ジョブ完了時にキューから次のジョブを自動的に取り出して処理する。Running Mapでアクティブジョブを追跡し、maxConcurrentに達した場合はdequeueを保留する。

**実装ファイル**: `src/export/export-job-queue.ts`

### 3. キュー位置追跡とETA推定 🔵

**信頼性**: 🔵 *REQ-226 ExportMetricsCollector の平均処理時間メトリクスより*

キュー内の位置をリアルタイムで追跡する。ETAは平均ジョブ処理時間（ExportMetricsCollectorから取得）× 前方のジョブ数 で推定する。位置は優先度別に計算する（高優先度ジョブが前に割り込むため）。

**実装ファイル**: `src/export/export-job-queue.ts`

### 4. フェアスケジューリング 🔵

**信頼性**: 🔵 *一般的なジョブキューパターンより*

低優先度ジョブの飢餓を防ぐため、一定間隔（デフォルト30秒）で最も古い低優先度ジョブを昇格させる。starvationPreventionInterval で設定可能。

**実装ファイル**: `src/export/export-job-queue.ts`

### 5. ExportMetricsCollector 統合 🔵

**信頼性**: 🔵 *REQ-226 ExportMetricsCollector 設計より*

ExportJobQueue のイベントを ExportMetricsCollector に統合する。queue_size、queue_wait_time_ms、queue_dequeue_count、queue_priority_distribution の4メトリクスを追加する。

**実装ファイル**: `src/export/export-job-queue.ts`、`src/export/export-metrics-collector.ts`
