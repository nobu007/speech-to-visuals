## タスク概要

同一のシーンデータから複数フォーマット（SVG/Lottie/PNG/PDF）でエクスポートした際、
出力間でシーン構成・色・ラベルが一貫していることを検証するテストを実装する。
現在、各フォーマットは独立してテストされているが、フォーマット間の一貫性検証が存在しない。

## 主要実装項目

### 1. SVG ↔ Lottie シーン構成一貫性検証 🟡

**信頼性**: 🟡 *両フォーマットの実装から推測*

同一シーンデータから SVG と Lottie を生成し、以下を比較:
- シーン数が一致
- 各シーンのタイプ順序が一致
- シーンラベル（テキスト）が一致

**テストファイル**: `tests/integration/cross-format-consistency.test.ts`

### 2. シーンタイプ別色の横断一貫性検証 🔵

**信頼性**: 🔵 *sceneTypeToFillColor() の実装が両フォーマットで共有されているため*

- intro: SVG の背景色と Lottie shape の fill が #1a1a2e
- content: 同 #16213e
- outro: 同 #0f3460
- 色がフォーマット間で一致することを検証

### 3. タイミング・フレーム計算の横断一貫性検証 🟡

**信頼性**: 🟡 *SVG CSS animation と Lottie keyframes の計算ロジックからの推測*

- フェードイン/フェードアウト時間が SVG と Lottie で一致
- 総再生時間が一致
- フレームレート換算が正しい

## 基本的なテスト要件

### テストケース1: Scene structure consistency 🟡

**信頼性**: 🟡 *両フォーマット生成ロジックからの推測*

- Given: 5シーンのデータ
- When: SVG + Lottie の両フォーマットでエクスポート
- Then: シーン数・タイプ順序・ラベルが一致

### テストケース2: Color consistency 🔵

**信頼性**: 🔵 *sceneTypeToFillColor 共有実装より*

- Given: 各シーンタイプを含むデータ
- When: SVG + Lottie エクスポート
- Then: シーンタイプ別色が両フォーマットで一致

### テストケース3: Timing consistency 🟡

**信頼性**: 🟡 *タイミング計算ロジックからの推測*

- Given: カスタム frame 設定のシーンデータ
- When: SVG + Lottie エクスポート
- Then: 総再生時間とフェード時間が一致
