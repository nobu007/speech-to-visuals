## 注意事項

- React コンポーネントの props 型定義は既存の interfaces.ts 型を活用すること
- Remotion コンポーネントの props は Remotion の型システムに準拠すること
- shadcn/ui の any 型は外部パッケージの型定義不足によるものが多い - 対象外とする
- イベントハンドラーの any 型は適切な React イベント型に置換すること
