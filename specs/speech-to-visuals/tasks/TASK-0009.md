## 実装詳細

### 1. テストヘルパー関数 (src/test/helpers.ts) 🔵

**信頼性**: 🔵 *note.md テストセクション・Jest 30 ベストプラクティスより*

テスト全体で使用するヘルパー関数を実装する。

機能:
- `createMockRequest(overrides?)`: Express Request モックの生成
- `createMockResponse()`: Express Response モックの生成（jest.fn() ベース）
- `createMockNext()`: Express NextFunction モックの生成
- `waitMs(ms: number)`: 非同期テスト用の待機ヘルパー
- `createTestEnv(vars: Record<string, string>)`: 環境変数モックの設定・復元
- `suppressConsole()`: テスト中のコンソール出力抑制

**実装ファイル**: `src/test/helpers.ts`

### 2. Whisper モックファクトリー (src/test/mocks/whisper.ts) 🔵

**信頼性**: 🔵 *architecture.md AIモジュール・PIPELINE_FLOW.md Stage 1より*

Whisper 音声認識のモックファクトリー。

機能:
- `createWhisperMock()`: Whisper モックインスタンスの生成
- `mockTranscriptionResult()`: 文字起こし結果のモックデータ生成
  - テキスト、タイムスタンプ、言語、セグメント情報
- `mockSrtOutput()`: SRT フォーマット出力のモック
- デフォルトの正常系モックとエラー系モックのプリセット
- 遅延シミュレーション機能

**実装ファイル**: `src/test/mocks/whisper.ts`

### 3. Gemini API モックファクトリー (src/test/mocks/gemini.ts) 🔵

**信頼性**: 🔵 *architecture.md AIモジュール・PIPELINE_FLOW.md Stage 2より*

Gemini LLM API のモックファクトリー。

機能:
- `createGeminiMock()`: Gemini API クライアントモックの生成
- `mockAnalysisResult()`: 分析結果のモックデータ生成
  - エンティティ、関係性、図解タイプ、サマリー、キーフレーズ
- `mockComplexityScore()`: 複雑度スコアのモック
- プリセットシナリオ:
  - `mockFlowDiagramResult()`: フロー図解の分析結果
  - `mockTreeDiagramResult()`: ツリー図解の分析結果
  - `mockTimelineDiagramResult()`: タイムライン図解の分析結果
  - `mockMatrixDiagramResult()`: マトリックス図解の分析結果
  - `mockCycleDiagramResult()`: サイクル図解の分析結果
- エラーシナリオ: タイムアウト、レート制限、無効レスポンス

**実装ファイル**: `src/test/mocks/gemini.ts`

### 4. Supabase クライアントモックファクトリー (src/test/mocks/supabase.ts) 🔵

**信頼性**: 🔵 *architecture.md データベース構成・supabase/migrations/ より*

Supabase クライアントのモックファクトリー。

機能:
- `createSupabaseMock()`: Supabase クライアントモックの生成

- `mockAuthClient()`: 認証クライアントのモック
  - `signIn()`, `signUp()`, `signOut()`, `getSession()`
- `mockStorageClient()`: ストレージクライアントのモック
  - `upload()`, `getPublicUrl()`, `remove()`
- チェーンメソッドのモックパターン（PostgrestBuilder パターン）

**実装ファイル**: `src/test/mocks/supabase.ts`

## 注意事項

- モックは実際のAPIのインターフェースと正確に一致させること（型安全性の確保）
- テストデータジェネレーターはデフォルト値で常に有効なデータを生成すること
- Supabase のチェーンメソッド（`.select().eq().single()`）のモックは特別な注意が必要
- モックのカスタマイズは `jest.fn().mockReturnValue()` パターンで統一すること
- テスト終了時には `jest.clearAllMocks()` または `jest.restoreAllMocks()` でクリーンアップすること
- テストフィクスチャは機密データを含まないこと
