## 背景

[TASK-0244 §残存 obligation](TASK-0244.md) で `隣接 live silent-corruption 候補` として先出しされていた 3 件のうち、最重要経路である `HealthCheckService.checkPipelineHealth()` を修正する。`checkMemoryHealth()`（MW-022）と `checkCacheHealth()`（MW-023）で閉じた NaN-routing silent corruption クラスと完全に同型のトラップであり、`realTimeMonitor.getSnapshot()` 戻り値の `successRate` / `avgProcessingTime` が backend omit / non-finite（backend が `NaN` を返す）のとき:

```ts
// src/monitoring/health-check-service.ts (修正前)
const successRate = snapshot.pipeline.successRate;
const activeRequests = snapshot.pipeline.activeRequests;
const avgProcessingTime = snapshot.pipeline.avgProcessingTime;

if (successRate > 0.95 && avgProcessingTime < 60000) {  // undefined > 0.95 = false, NaN < 60000 = false
  // healthy
} else if (successRate > 0.80 && avgProcessingTime < 120000) {
  // degraded
} else {
  status = 'unhealthy';
  message = `Pipeline is experiencing issues (${(successRate * 100).toFixed(1)}% success rate)`;
}
```

両述語が `false` のため else 枝に落ち、`(undefined * 100).toFixed(1)` または `(NaN * 100).toFixed(1)` で `"NaN%"` を含む fabricated unhealthy verdict を返し、`generateRecommendations` が **unknown observation window** で「CRITICAL」相当を emit する silent corruption が発生する。

## 修正

`src/monitoring/health-check-service.ts` の `checkPipelineHealth()` 冒頭（`try { snapshot = realTimeMonitor.getSnapshot(); } catch …` 直後）に MW-022/MW-023 と同型の typeof + Number.isFinite ガードを追加:

```ts
if (
  typeof successRate !== 'number' ||
  typeof avgProcessingTime !== 'number' ||
  !Number.isFinite(successRate) ||
  !Number.isFinite(avgProcessingTime)
) {
  const successRateType =
    successRate === undefined ? 'undefined' : typeof successRate;
  const avgProcessingTimeType =
    avgProcessingTime === undefined ? 'undefined' : typeof avgProcessingTime;
  logger?.warn?.(
    `[HealthCheck] Pipeline health check unavailable: backend omitted fields ` +
      `(successRate=${successRateType}, avgProcessingTime=${avgProcessingTimeType})`
  );
  return {
    status: 'degraded',
    message: 'Pipeline monitoring unavailable: backend omitted successRate/avgProcessingTime',
    latency: Date.now() - startTime,
    lastChecked: Date.now(),
  };
}
```

これにより:
- `successRate = undefined` または `avgProcessingTime = undefined` → guard 発火 → `degraded` (fail-loud)
- `successRate = NaN` または `avgProcessingTime = NaN` → 同上
- 妥当な finite 入力時 → 既存ロジック healthy / degraded / unhealthy の数値判定を継続

## テスト

`tests/unit/monitoring/health-check-service.test.ts` の `pipeline health check` describe ブロックに 2 件追加:
