### 1. quality-gate.test.ts 29 node → 0（fail-loud `requireCriterionResult` helper）

`result.results.find(r => r.criterionName === 'X')` 結果の `x!.passed` / `x!.score` 計 29 node を、ファイル内 helper に置換:

```ts
function requireCriterionResult(
  evaluation: StageEvaluationResult,
  criterionName: string,
): StageCriterionResult {
  const found = evaluation.results.find(r => r.criterionName === criterionName);
  if (found === undefined) {
    throw new Error(`criterion result not found: ${criterionName}`);
  }
  return found;
}
```

**挙動保存の根拠**: 旧コードの不在時挙動は bare `expect(x).toBeDefined()` 失敗 = RED。helper は不在時に criterion 名を含む Error を throw するため **同一 verdict（RED）でメッセージが診断可能**。`expect(x).toBeDefined()` 行（15 件）は helper が同保証を担うため削除。Phase 148 `requireAlertRule` と同型。
