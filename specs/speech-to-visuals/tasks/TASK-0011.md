## 実装詳細

### 1. WhisperTranscriber クラス実装 🔵

**信頼性**: 🔵 *PIPELINE_FLOW.md Stage 1, dataflow.md機能1より*

@remotion/install-whisper-cppを使用した音声ファイル文字起こしの中核クラス。Whisperモデルのロード、音声ファイルの前処理、文字起こし実行、結果のパース処理を実装する。対応形式はMP3/WAV/OGG/M4A、最大ファイルサイズ50MB。言語自動検出(ja/en)または手動指定に対応し、タイムスタンプ付きセグメントとして結果を返す。

```typescript
interface TranscriptionResult {
  text: string;
  segments: TranscriptionSegment[];
  language: 'ja' | 'en';
  duration: number;
}

interface TranscriptionSegment {
  id: number;
  start: number;
  end: number;
  text: string;
  confidence: number;
}
```

**実装ファイル**: `src/transcription/whisper-transcriber.ts`

### 2. SRTジェネレーター実装 🔵

**信頼性**: 🔵 *PIPELINE_FLOW.md Stage 1, dataflow.md機能1より*

タイムスタンプ付きセグメントからSRT形式のキャプションファイルを生成するモジュール。SRTフォーマット仕様に準拠し、セグメント番号、タイムコード(`HH:MM:SS,mmm --> HH:MM:SS,mmm`)、テキストを出力する。

**実装ファイル**: `src/transcription/srt-generator.ts`

### 3. ファイルバリデーション実装 🔵

**信頼性**: 🔵 *PIPELINE_FLOW.md Stage 1, dataflow.md機能1より*

音声ファイルのバリデーション処理。対応形式(MP3/WAV/OGG/M4A)の確認、ファイルサイズ制限(最大50MB)のチェック、ファイル破損検知を実装する。

**実装ファイル**: `src/transcription/whisper-transcriber.ts`

## 注意事項

- @remotion/install-whisper-cppのWhisperモデルは初回起動時にダウンロードが必要なため、CI環境でのモデルキャッシュ設定に注意すること
- 大きなファイル(50MB付近)の処理ではメモリ使用量に注意し、ストリーミング処理を検討すること
- Whisperのモデルサイズ(ggml-base.bin等)によって精度と速度がトレードオフになるため、要件に応じたモデル選択を行うこと
- 非日本語・非英語の音声が入力された場合はエラーとするか、ベストエフォートで処理するかを仕様確認すること
