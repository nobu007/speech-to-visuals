## 主要実装項目

### 1. POST /api/render エンドポイント実装 🔵

**信頼性**: 🔵 *api-endpoints.md Pipeline Operations API より*

Express API ルートハンドラを作成。フロントエンドからシーンデータとオプション（resolution, fps, codec）を受信し、Remotion renderMedia に委譲して動画 URL とメタデータ（fileSize, duration）を返す。

- リクエスト: `{ sceneData: { ... }, options: { resolution: "1080p", fps: 30, codec: "h264" } }`
- レスポンス: `{ success: true, videoUrl: "/output/video-xxx.mp4", fileSize: 5242880, duration: 12.5 }`
- 主要コンシューマー: `PipelineInterface.tsx`

**実装ファイル**: `src/hooks/useFrameworkPipeline.ts`（フロントエンド統合）、`src/api/`（バックエンドルート）

### 2. POST /api/git/commit エンドポイント実装 🔵

**信頼性**: 🔵 *api-endpoints.md・useFrameworkPipeline.ts:265 TODO より*

品質閾値到達時に自動コミットを実行するエンドポイント。コミットメッセージと対象ファイル一覧を受信し、フレームワークに委譲してコミットハッシュを返す。

- リクエスト: `{ message: "feat(pipeline): improvement iteration N", files: ["src/analysis/llm-service.ts"] }`
- レスポンス: `{ success: true, commitHash: "abc1234" }`
- 主要コンシューマー: `FrameworkDashboard.tsx`

**実装ファイル**: `src/hooks/useFrameworkPipeline.ts:265`

### 3. GET /api/iteration-log エンドポイント実装 🔵

**信頼性**: 🔵 *api-endpoints.md・useFrameworkPipeline.ts:363 TODO より*

イテレーションログを取得するエンドポイント。品質メトリクスの履歴と改善トレンドを返す。

- レスポンス: `{ iterations: [{ id, phase, qualityScore, timestamp }], qualityTrend: "improving", recommendations: [...] }`
- 主要コンシューマー: `FrameworkDashboard.tsx`

**実装ファイル**: `src/hooks/useFrameworkPipeline.ts:363`

### 4. GET /api/framework/status エンドポイント実装 🔵

**信頼性**: 🔵 *api-endpoints.md・FrameworkDashboard.tsx:164 TODO より*

フレームワーク実行ステータスを取得するエンドポイント。現在フェーズ・品質スコア・実行中フラグ・改善推奨を返す。

- レスポンス: `{ success: true, currentPhase: "quality_improvement", qualityScore: 95, isRunning: true, improvementSuggestions: [] }`
- 主要コンシューマー: `FrameworkDashboard.tsx`

**実装ファイル**: `src/components/FrameworkDashboard.tsx:164`

### 5. セマンティック分析・トピックモデリング実装 🟡

**信頼性**: 🟡 *scene-segmenter.ts の TODO コメントから妥当な推測*
