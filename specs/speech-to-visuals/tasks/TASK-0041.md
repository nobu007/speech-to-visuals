## 実装詳細

### 1. Multi-format Exporter モジュール実装 🔵

**信頼性**: 🔵 *src/export/multi-format-exporter.ts, architecture.mdより*

複数形式のエクスポートを統合的に管理するモジュール。各エクスポーターの呼び出しと出力設定の管理を行う。

- エクスポート形式の登録と管理
- エクスポート設定インターフェース:
  ```typescript
  interface ExportOptions {
    format: 'svg' | 'png' | 'pdf' | 'json';
    quality?: number; // 1-100 (PNG/PDF用)
    dpi?: number; // 72, 150, 300 (PNG/PDF用)
    includeMetadata?: boolean; // JSON用
    includeStyles?: boolean; // SVG用
  }
  ```
- エクスポート進捗のトラッキング
- ファイル名の自動生成（プロジェクト名_日付_形式）

**実装ファイル**: `src/export/multi-format-exporter.ts`

### 2. SVG エクスポーター実装 🔵

**信頼性**: 🔵 *src/export/multi-format-exporter.tsより*

図解データからSVGファイルを生成するエクスポーター。

- 図解データからSVG DOMの構築
- スタイル情報のインライン化
- ビューボックスの適切な設定
- フォントの埋め込み（オプション）
- UTF-8エンコーディング

**実装ファイル**: `src/export/svg-exporter.ts`

### 3. PNG エクスポーター実装 🔵

**信頼性**: 🔵 *src/export/multi-format-exporter.ts, architecture.mdより*

図解データからPNG画像を生成するエクスポーター。Canvas API または Remotion の静止画レンダリングを活用する。

- SVG → Canvas → PNG の変換パイプライン
- DPI設定（72, 150, 300）
- 品質設定（PNGは可逆圧縮だが、リサイズ時の品質調整）
- 背景色の設定（透明/白/カスタム）
- Remotion `renderStill()` を使用した高品質出力

**実装ファイル**: `src/export/png-exporter.ts`

### 4. PDF エクスポーター実装 🔵

**信頼性**: 🔵 *architecture.mdより*

図解データからPDFドキュメントを生成するエクスポーター。

- ページサイズ設定（A4, A3, カスタム）
- 品質/解像度設定
- タイトルとメタデータの埋め込み
- 複数図解のマルチページ対応（オプション）

**実装ファイル**: `src/export/pdf-exporter.ts`

### 5. JSON エクスポーター実装 🔵

**信頼性**: 🔵 *src/export/multi-format-exporter.tsより*

図解データの構造化JSONエクスポート。他システムとの連携用データとして提供する。

- 整形JSON出力（インデント2スペース）

## 注意事項

- ブラウザ上でのファイル生成にはBlob APIを使用し、URL.createObjectURLでダウンロードリンクを生成すること
- PDF生成には軽量ライブラリ（jspdf等）の使用を検討すること
- SVGエクスポート時は、外部スタイルシートの参照をインライン化すること
- PNG生成時のCanvas描画は、クロスオリジン制約に注意すること
- 大きな図解のエクスポートではメモリ使用量に注意すること
- Remotion MediaFlowを活用して、動画と静止画の統合的なエクスポートパイプラインを構築すること
