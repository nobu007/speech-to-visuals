## タスク概要

高度なビジュアル機能を提供するAdvancedLayoutEngineを実装する。テーマシステム（dark/light/professional/vibrant）、アニメーション制御、カラースキーム、ノード形状・エッジスタイルの高度化により、基本レイアウトを視覚的に強化する。interfaces.tsで定義された42の高度レイアウト型に対応する。

## 実装詳細

### 1. AdvancedLayoutEngine コアクラス 🔵

**信頼性**: 🔵 *実装 advanced-layouts.ts より*

メインエンジンクラス。基本レイアウト結果を高度なビジュアル表現に変換。

**実装ファイル**: `src/visualization/advanced-layouts.ts`

```typescript
export class AdvancedLayoutEngine {
  constructor(options?: AdvancedLayoutOptions) {}
  apply(layout: LayoutResult, diagramType: DiagramType): AdvancedLayoutOutput {}
  setTheme(theme: VisualTheme): void {}
  setAnimationStyle(style: 'smooth' | 'bouncy' | 'minimal'): void {}
}
```

### 2. VisualTheme テーマシステム 🔵

**信頼性**: 🔵 *interfaces.ts VisualTheme定義より*

4つの事前定義テーマとテーマ自動検出。

**実装ファイル**: `src/visualization/advanced-layouts.ts`

- dark: ダーク背景、高コントラストノード
- light: ライト背景、ソフトエッジ
- professional: ビジネス向け青基調
- vibrant: カラフル・高エネルギー
- 自動検出: 時刻ベース（6-18時light、18-6時dark）

### 3. AdvancedLayoutNode 拡張ノード 🔵

**信頼性**: 🔵 *interfaces.ts AdvancedLayoutNode定義より*

基本NodeDatumを拡張し、形状・グラデーション・シャドウ・アニメーションを追加。

**実装ファイル**: `src/visualization/advanced-layouts.ts`

- shape: rectangle/rounded/circle/hexagon
- gradient: ノードグラデーション効果
- shadow: ドロップシャドウ
- animation: 入場アニメーション（fade/scale/bounce）

### 4. AdvancedLayoutEdge 拡張エッジ 🔵

**信頼性**: 🔵 *interfaces.ts AdvancedLayoutEdge定義より*

基本EdgeDatumを拡張し、スタイル・アニメーション・太さ・矢印を追加。

**実装ファイル**: `src/visualization/advanced-layouts.ts`

- style: solid/dashed/dotted/gradient
- animated: フロー アニメーション
- thickness: エッジ太さ制御
- arrowHead: 矢印スタイル
- points: カスタム経由点

### 5. AdvancedLayoutCanvas キャンバス設定 🔵

**信頼性**: 🔵 *interfaces.ts AdvancedLayoutCanvas定義より*

高度キャンバス設定と背景効果。

- 解像度対応（720p/1080p/4K）
- 背景グラデーション
- グリッドオーバーレイ
- セーフゾーンマージン
