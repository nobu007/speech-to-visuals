## 主要実装項目

### 1. VisualBalanceScorer クラス 🟡

**信頼性**: 🟡 *REQ-079 の定義に基づく新規実装*

`PositionedNode[]` を受け取り、3つのバランス指標を計算するスコアラークラス。

**実装ファイル**: `src/visualization/visual-balance-scorer.ts`

```typescript
export interface VisualBalanceResult {
  overallScore: number;          // 0.0~1.0 統合スコア
  centroidDeviation: number;     // 0.0~1.0 重心偏差（1.0=中央に配置）
  quadrantBalance: number;       // 0.0~1.0 象限バランス（1.0=完全均等）
  densityUniformity: number;     // 0.0~1.0 密度均一性（1.0=完全均一）
  centroid: { x: number; y: number };
  quadrantCounts: [number, number, number, number]; // 各象限のノード数
}

export class VisualBalanceScorer {
  calculateVisualBalance(
    nodes: PositionedNode[],
    bounds: { width: number; height: number }
  ): VisualBalanceResult;
}
```

### 2. 重心偏差計算 🔵

**信頼性**: 🔵 *既存 LayoutEvaluator.calculateLayoutBalance() の発展*

全ノードの重心位置とキャンバス中心との偏差を正規化して計算。

### 3. 象限バランス計算 🟡

**信頼性**: 🟡 *REQ-079 定義に基づく推測*

キャンバスを4象限に分割し、各象限のノード数分布の均等性を評価。完全に均等な分布でスコア1.0。

### 4. 密度均一性計算 🟡

**信頼性**: 🟡 *REQ-079 定義に基づく推測*

グリッドベースの密度マップ（例: 4x4グリッド）で各セルのノード密度を計算し、密度のばらつきを標準偏差で評価。

## 基本的なテスト要件

### 重心偏差テスト 🔵

**信頼性**: 🔵 *既存パターンに基づく*

- 全ノードが中心に配置 → centroidDeviation ≈ 1.0
- 全ノードが左上に偏る → centroidDeviation < 0.5
- 空ノード配列 → スコア1.0（エラーなし）

### 象限バランステスト 🟡

**信頼性**: 🟡 *新規ロジックのテスト*

- 4象限に均等配置 → quadrantBalance ≈ 1.0
- 全ノードが1象限に集中 → quadrantBalance < 0.3

### 密度均一性テスト 🟡

**信頼性**: 🟡 *新規ロジックのテスト*

- グリッド全体に均等配置 → densityUniformity ≈ 1.0
- 全ノードが1箇所に密集 → densityUniformity < 0.3
