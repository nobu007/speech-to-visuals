## タスク概要

言語・文化圏に応じたレイアウト適応を行うCulturalLayoutAdapterを実装する。RTL（右→左）読み方向、TTB（上→下）縦書き、階層強調度合い、ビジュアルスタイル（ミニマル/表現豊か/技術的）を文化コンテキストに基づいて自動調整する。

## 実装詳細

### 1. CulturalLayoutAdapter コアクラス 🟡

**信頼性**: 🟡 *設計文書 architecture.md に記載あり、実装詳細は推測*

文化コンテキストに基づくレイアウト適応アダプター。

**実装ファイル**: `src/visualization/strategies/CulturalLayoutAdapter.ts`

```typescript
export class CulturalLayoutAdapter {
  constructor(locale?: string) {}
  adapt(layout: LayoutResult, diagramType: DiagramType): LayoutResult {}
  setReadingDirection(direction: 'LTR' | 'RTL' | 'TTB'): void {}
  setHierarchyEmphasis(level: 'strong' | 'flat'): void {}
  setVisualStyle(style: 'minimalist' | 'expressive' | 'technical'): void {}
}
```

### 2. RTL レイアウトミラーリング 🟡

**信頼性**: 🟡 *dataflow.md にRTL記載あり、実装詳細は推測*

右→左読み方向へのレイアウトミラーリング。

- X座標の反転（canvas.width - x）
- フロー方向のLR→RL変換
- エッジ矢印の方向反転
- テキスト配置の調整

### 3. TTB 縦書き対応 🟡

**信頼性**: 🟡 *dataflow.md にTTB記載あり、実装詳細は推測*

上→下縦書き文化へのレイアウト調整。

- CJK文字向けの縦書きノードテキスト
- ツリー/フローのTB方向デフォルト化
- 縦書き時のノードサイズ調整（高さ>幅）

### 4. 階層・スタイル適応 🔵

**信頼性**: 🔵 *実装 CulturalLayoutAdapter.ts より*

文化に応じた階層強調とビジュアルスタイル調整。

- strong: 階層レベルの視覚的強調（サイズ・色差）
- flat: フラットな階層表現
- minimalist: 最限のビジュアル要素
- expressive: 豊かな装飾と色彩
- technical: 技術文書向けの厳格なスタイル
