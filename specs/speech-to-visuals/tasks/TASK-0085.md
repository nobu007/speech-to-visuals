### 2. 型置換戦略 🔵

**信頼性**: 🔵 *既存コードパターンから*

各 `any` 型を適切な型に置き換える:

- モック関数の引数: `jest.Mock<any>` → `jest.Mock<ReturnType, Arguments>` または `jest.MockedFunction<typeof fn>`
- テストデータ: `any` → 対応するインターフェース型または `Record<string, unknown>`
- キャスト: `as any` → `as unknown as TargetType`（最小限）または型ガード使用

**実装ファイル**: 上記4ファイル

```typescript
// 修正例:
// Before:
const mockFn = jest.fn() as any;
// After:
const mockFn = jest.fn<ReturnType, ParametersType>();
```

- `jest.Mock<any>` パターンは `jest.MockedFunction` またはジェネリック付き `jest.Mock<R, A>` に置き換える
