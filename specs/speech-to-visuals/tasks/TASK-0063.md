## タスク概要

20ノード以上の大規模ダイアグラムに対応するComplexLayoutEngineを実装する。マルチレベルグラフ粗視化・非粗視化アルゴリズム、コミュニティ検出クラスタリング、収束検出付き力指向シミュレーションを組み合わせ、大規模グラフでも高品質なレイアウトを提供する。

大規模グラフ向けメインエンジン。マルチレベルアプローチで20+ノードの最適配置。

**実装ファイル**: `src/visualization/complex-layout-engine.ts`

```typescript
export class ComplexLayoutEngine {
  constructor(config?: ComplexLayoutConfig) {}
  async layout(data: DiagramData): Promise<LayoutResult> {}
  private coarsen(graph: Graph): Graph[] {}
  private uncoarsen(coarsened: Graph[], baseLayout: Map<string, Point>): LayoutResult {}
  private detectCommunities(graph: Graph): ClusterData[] {}

}
```

### 2. マルチレベル粗視化 🔵

**信頼性**: 🔵 *実装 complex-layout-engine.ts より*

グラフを段階的に簡略化し、粗いレベルで初期配置を決定。

- マッチングベースのノード統合
- レベルごとのグラフ縮小
- 3〜5レベルの粗視化

### 3. コミュニティ検出クラスタリング 🔵

**信頼性**: 🔵 *実装 complex-layout-engine.ts より*

ネットワーク構造のコミュニティを検出し、クラスタ単位で配置。

- モジュラリティ最大化
- クラスタ内・クラスタ間の力調整
- クラスタの円形配置

### 4. 力指向シミュレーション 🔵

**信頼性**: 🔵 *実装 complex-layout-engine.ts より*

反発力・引力を用いた最適配置。収束検出で無駄な計算を削減。

- 斥力: クーロン力モデル
- 引力: フック則モデル
- 収束閾値: 位置変動 < 0.01px
- 最大反復: 100回

### 5. パフォーマンスモニタリング 🔵

**信頼性**: 🔵 *実装 complex-layout-engine.ts より*

リアルタイムパフォーマンス追跡と適応的最適化。

- FPS監視（ターゲット60FPS）
- メモリ使用量追跡（上限256MB）
- レイアウト時間計測（上限5秒）
- 適応的品質調整
