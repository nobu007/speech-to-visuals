### 1. websocket-handler.test.ts 21 node → 0（fail-loud `requireEventHandler` helper）

mock `.on()` の `.find()?.[1]` キャプチャ後の `connectionCb!` / `joinCb!` / `leaveCb!` / `disconnectCb!` 呼び出し 21 node を、ファイル内 helper に置換:

```ts
function requireEventHandler(
  calls: unknown[][],
  event: string,
): (...args: unknown[]) => void {
  const handler = calls.find((c) => c[0] === event)?.[1];
  if (typeof handler !== 'function') {
    throw new Error(`handler for "${event}" was not registered`);
  }
  return handler as (...args: unknown[]) => void;
}
```

**挙動保存の根拠**: 旧コードの不在時挙動は `undefined(…)` TypeError = RED。helper は不在時に未登録 event 名を含む Error を throw するため **同一 verdict（RED）でメッセージが診断可能**。`typeof !== 'function'` check は「未登録」と「登録済みだが空配列」の両方を捕捉する。
