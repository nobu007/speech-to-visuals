## 背景

[TASK-0244 §残存 obligation](TASK-0244.md) の `隣接 live silent-corruption 候補` 3 件のうち最後の 1 件。TC-343/344/345（REQ-348/349/350）で checkCacheHealth / checkPipelineHealth / checkLLMHealth を閉じたのと同一の NaN-routing silent corruption が `checkErrorRecoveryHealth()` に残存していた:

```ts
// src/monitoring/health-check-service.ts (修正前)
const errorRate = snapshot.errors.errorRate;
const recoveryRate = snapshot.errors.recoverySuccessRate;

if (errorRate < ERROR_RATE_WARNING_THRESHOLD && recoveryRate > 0.80) {
  // healthy
} else if (errorRate < ERROR_RATE_CRITICAL_THRESHOLD || recoveryRate > 0.50) {
  // degraded: "Error recovery is degraded (NaN% error rate, 90.0% recovery rate)"
} else {
  // unhealthy: "Error recovery is failing (NaN.0% error rate, NaN.0% recovery rate)"
}
```

`realTimeMonitor.getSnapshot().errors` の `errorRate` / `recoverySuccessRate` が backend omit / non-finite のとき、閾値チェーンの NaN/undefined オペランド比較（`NaN < 0.05`・`undefined > 0.80` 等）はすべて FALSE に化け、else-if / else 枝へ流れ込んで `toFixed` が `"NaN%"` を含む fabricated verdict を生成する。**修正前実測**（RED 検証）:

- `errorRate: NaN` → `"Error recovery is degraded (NaN% error rate, 90.0% recovery rate)"`
- `recoverySuccessRate: undefined` → `"Error recovery is degraded (2.0% error rate, NaN% recovery rate)""`

この verdict は `performHealthCheck` の overall status 計算と `generateRecommendations` に伝播し、unknown observation window に対して degraded/unhealthy を報告する silent corruption となる。

## 修正

`checkErrorRecoveryHealth()` の `try { snapshot = … } catch …` 直後に、Phase 160 抽出の `isFiniteMetric` 述語で REQ-347〜350 と同型のガードを前置（commit 136e5f65）:

```ts
if (!isFiniteMetric(errorRate) || !isFiniteMetric(recoveryRate)) {
  const errorRateType = errorRate === undefined ? 'undefined' : typeof errorRate;
  const recoveryRateType =
    recoveryRate === undefined ? 'undefined' : typeof recoveryRate;
  logger?.warn?.(
    `[HealthCheck] Error recovery health check unavailable: backend omitted fields ` +
      `(errorRate=${errorRateType}, recoverySuccessRate=${recoveryRateType})`
  );
  return {
    status: 'degraded',
    message:
      'Error recovery unavailable: backend omitted/non-finite errorRate/recoverySuccessRate',
    latency: Date.now() - startTime,
    lastChecked: Date.now(),
  };
}
```

これにより `checkXxxHealth` 系メソッドの未ガード metric read は **全完**（memory=REQ-347・cache=REQ-348・pipeline=REQ-349・llm=REQ-350・errorRecovery=REQ-351。performance は try-catch 別系統）。
