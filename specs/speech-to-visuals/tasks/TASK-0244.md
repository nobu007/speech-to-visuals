## 背景

[TASK-0243 §義務 A](TASK-0243.md) で宣言された「次サイクル obligation」のうち、MW-022 が閉じた `HealthCheckService.checkMemoryHealth()` の heap field 欠損経路と隣接する `HealthCheckService.checkCacheHealth()` を、memory の recurring-bug-classes.md "Self-referential rate/proportion formula"（Phase 142 commit 2428e472 が `intelligent-cache.updateHitRate` の write path を閉じた live instance）の延長線上で hunt したところ、同一 silent corruption クラスの **read path ライブ instance** を発見した:

```ts
// src/monitoring/health-check-service.ts (修正前)
const totalHits = stats.totalHits ?? Math.round(stats.hitRate * stats.totalEntries);
const totalMisses = stats.totalMisses ?? Math.round((1 - stats.hitRate) * stats.totalEntries);
const hitRate = totalHits / (totalHits + totalMisses) || 0;
```

`globalCache.getStats()` 戻り値の `stats.hitRate` / `stats.totalEntries` が backend omit / non-finite（broken cache が `hitRate = NaN` を返す）のとき、`Math.round(undefined * N) = NaN` または `Math.round(NaN * N) = NaN` に流れ込み、`NaN / (NaN + NaN) = NaN` → `|| 0` で `0%` → "Cache is ineffective (0% hit rate)" → **unhealthy** を返し、`generateRecommendations` が "CRITICAL: Cache is ineffective - review caching strategy" を **unknown observation window** で emit する silent corruption が発生する。

MW-022 と完全に同型のトラップ（API 戻り `T | undefined` を caller が素読み → silent NaN-routing → fabricated unhealthy）であり、`checkMemoryHealth()` の修正で閉じた同一 contract の隣接インスタンス。本タスクは義務 A 2 件目としてこのパスを fail-loud 化する。

## 修正

`src/monitoring/health-check-service.ts` の `checkCacheHealth()` 冒頭（`try { stats = globalCache.getStats(); } catch …` 直後）に MW-022 と同型のガードを追加:

```ts
if (
  typeof stats.hitRate !== 'number' ||
  typeof stats.totalEntries !== 'number' ||
  !Number.isFinite(stats.hitRate) ||
  !Number.isFinite(stats.totalEntries)
) {
  logger?.warn?.(
    `[HealthCheck] Cache health check unavailable: backend returned non-finite or omitted metrics ` +
      `(hitRate=${typeof stats.hitRate === 'number' ? stats.hitRate : 'undefined'}, ` +
      `totalEntries=${typeof stats.totalEntries === 'number' ? stats.totalEntries : 'undefined'})`
  );
  return {
    status: 'degraded',
    message: 'Cache monitoring unavailable: backend returned non-finite or omitted metrics',
    latency: Date.now() - startTime,
    lastChecked: Date.now(),
  };
}
```

これにより:
- `stats.hitRate = undefined` または `stats.hitRate = NaN` → guard 発火 → `degraded` (fail-loud)
- `stats.totalEntries = undefined` → 同上
- 妥当な finite 入力時 → 既存ロジック healthy / degraded / unhealthy の数値判定を継続
