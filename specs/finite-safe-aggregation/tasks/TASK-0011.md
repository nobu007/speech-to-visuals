## タスク概要

TASK-0010 が「未 triage の別大陸」として理由付き送りにした `src/framework/` と
`src/api/` を sweep 正本リスト化（下記「対象外」表がその成果物）し、
tier 分類で移行と判定した 3 ファイル 5 サイトを helper へ委譲する:

1. **`src/api/batch-processing-api.ts:411-412`（interface フィールド集計）** —
   `qualityScores` は `SimplePipelineResult.qualityScore`（pipeline→REST 境界を
   跨ぐ interface フィールド。EER-355 と同判定）。`??` は null/undefined しか
   置換しないので非有限値は total と average の両方を NaN 化し、REST レスポンスでは
   `averageQualityScore: null` として逐次化される。→ `safeSum` + `safeMean`。
2. **`src/framework/recursive-custom-instructions.ts:295-299`（誤述語 pre-filter）** —
   `filter(v => typeof v === 'number')` は NaN/±Infinity を通す（`typeof NaN ===
   'number'`）。モジュール score が NaN → `calculateOverallScore` →
   `passed = overallScore >= 0.8` が NaN 比較で常に false（silent fail）、
   +Infinity なら常に true（常時 pass）。→ `safeMean(Object.values(...))`
   （数値以外の除外は `Number.isFinite` が非強制なので旧 filter と同一）。
3. **`src/framework/continuous-learner.ts`（旧 497/502。userFeedback interface 値）** —
   `userFeedback` は未検証 public `learnFromUserFeedback(rating)` 境界経由
   （1-5 clamp 無し）。旧 `|| 0` falsy-guard は非有限 rating を 0 置換して
   average を引き下げ、満足度 3.0（許容線）の母集団で
   `[3×9, NaN] → 2.7 < 3.0` の偽 low-satisfaction insight を生成した。→
   `safeMean`（`?? NaN` は型用。population は `!== undefined` pre-filter 温存）。
