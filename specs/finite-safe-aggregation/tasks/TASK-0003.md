## 主要実装項目

### selector 内包 reduce の機械置換 🔵

**信頼性**: 🔵 *architecture.md D4 形式 A・D2 より*

**実装ファイル**: `src/analysis/llm-service.ts`

```ts
// 旧: const avg = entries.reduce((sum, e) => sum + (e.end - e.start), 0) / entries.length;
// 新:
import { safeMean } from '../lib/metrics-utils';
const avg = safeMean(entries.map(e => e.end - e.start));
```

mean 分母は有限要素数になるため、NaN 混入時のみ値が変化する（EDGE-001 該当）。
