## 主要実装項目

### 1. en pair: jfk.wav copy + human-entered 参照文字起こし 🔵

**信頼性**: 🔵 *architecture.md v1 構成ファイル表・Phase 29 実績（`public/jfk.wav` 352,078 byte ≒ 11.0 秒）より*

- `cp public/jfk.wav public/audio/jfk.wav`（本体は `scripts/transcribe.ts` 等が参照するため残置 — 344KB 重複は許容）
- `public/audio/jfk.txt`: 1961 年就任演説（public domain・米連邦政府の著作物）の当該 excerpt を public domain の演説本文から書き起こす。**`public/srt/jfk.srt` は過去 ASR 由来の循環リスクがあるため使わない**。CORPUS.md の provenance 行に「演説本文（public domain）から human-entered・音声内容と突合済み」と記載する 🟡（excerpt の正確な範囲は実装時に音声実長 ≒11 秒と整合する範囲で確定）

### 2. ja pair: maintainer 録音 + 原稿そのものの参照文字起こし 🔵（録音の実体は 🟡 maintainer input）

**信頼性**: 🔵 *REQ-423 (a)(b)・architecture.md v1 構成ファイル表より*

- `public/audio/ja-project-phases.txt`: 現 `public/audio/test-audio.txt`（「プロジェクト管理」読み上げ原稿）の内容を **verbatim** で移行（録音原稿 = 参照文字起こし。転写推定を介さないため構造的に循環しない）
- `public/audio/ja-project-phases.wav`: maintainer による読み上げ録音。規格: **WAV PCM 16kHz mono・60 秒以内**。録音・書き出し手順（16kHz mono への変換コマンド含む）を CORPUS.md に記載。ライセンスは録音者（maintainer）による **CC0 1.0 提供宣言**を CORPUS.md に記載 🟡
- **AI 実装 agent は合成音声で代用しない**（合成音は測定ではなく fail-loud 契約に反する）。録音が未提供の間、契約 test の ja 行は RED のままが正しい状態（born-DONE にしない）

### 3. CORPUS.md manifest + phantom metadata 掃除 🔵

**信頼性**: 🔵 *dataflow.md 機能2（三方突合）・architecture.md より*

- 表形式 manifest: `| file | language | durationSec | source | license | transcript provenance | 備考（変換手順）|`
- `sample-info.json` を削除（存在しない wav を説明する phantom metadata・code 参照は `docs/llm-wiki/**` の生成 inventory のみで実害なし）
- `test-audio.txt` は verbatim 移行後に削除

### 4. corpus 契約 test（TC-407-01）🔵

**信頼性**: 🔵 *TC-407-01 検証コマンド（corpus file × 参照文字起こし同伴 + ライセンス doc の存在を pin）より*

**実装ファイル**: `tests/scripts/real-audio-corpus.test.ts`

- `readdirSync('public/audio')` 相当（`import.meta.url` 基準の path 解理 — cwd 相対は flake 族）で audio file を列挙し、それぞれ同名 `.txt` が存在・CORPUS.md に行があることを検査
- 全 `.wav` について `parseWavHeader`（TASK-0314）で `audioFormat === 1` / `sampleRate === 16000` / `channels === 1` / `readWavDurationMs <= 60_000` を検査
- ja（`ja-*` 命名規約 or CORPUS.md language 列）と en が最低 1 file ずつ存在
- `sample-info.json` の不存在 pin（掃除の再発防止）
- 音声が 0 件の状態（= 整備前）に戻ったら RED することも確認（fail-loud — corpus 空は測定ではない）
