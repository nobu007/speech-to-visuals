## タスク概要

`StreamingProcessor.tsx` は placeholder 経路の結果（TASK-0319 で `placeholder: true` が立つ）を「実測」と同一視して品質 stats 表示（`averageConfidence * 100` :574）に出している。result の `placeholder` flag を component state に取り込み、placeholder 経路では (1) 偽の品質 stats を表示しない (2) placeholder 経路である旨の notice を出す — server 経路の D-1 開示・README「音声認識の現状」と同一の開示方針を streaming 経路の UI にも適用する。

**実装ファイル**: `src/components/StreamingProcessor.tsx`

### 2. 偽 stats 抑制と notice 表示 🔵 / 🟡

**信頼性**: 🔵 *dataflow.md「UI への開示データ」（抑制要件が明記）より。notice 形状は 🟡 *design-interview A9（実装時確定の明記）より*

- 実経路: 現行表示を維持

```tsx

```
