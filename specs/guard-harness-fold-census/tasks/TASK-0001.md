## 主要実装項目

### oracleRow / anchorRow factory（宣言時 fail-loud） 🔵

**信頼性**: 🔵 *interfaces.ts §4 検証規則・EDGE-001 より*

`id` 空・`corpus` 空・delta mode で `maxDelta` 未指定/非有限/≤0・`exactly < 0`・
`atLeast < 1`・`pattern.source` に `\n` を含む場合、即時 throw（エラーメッセージに
row id を含む）。

**実装ファイル**: `tests/guards/single-source-harness.ts`

### describeSingleSource 生成器 🔵

**信頼性**: 🔵 *D2/D3（round 48/50 の実績比較方式の型化）より*

- oracle(object-is): corpus 各 case で `expect(Object.is(canonical, retired)).toBe(true)`
- oracle(delta): Object.is 不一致 case のみ `|差| ≤ maxDelta` を検証し
  ループ後に `expect(deltaCount).toBeGreaterThan(0)`（witness 強制）
- anchor(occurs/occurs-at-least/ban): scope（既定 `'code'` = コメント行除外）で
  行ベース計数

**実装ファイル**: `tests/guards/single-source-harness.ts`

### 単体 test 🔵

**信頼性**: 🔵 *acceptance-criteria TC-001-01/E01/B01・TC-NFR-101-01 より*

- 最小 row 4 種（object-is / delta / occurs / ban）の生成 GREEN・test 名に row id
- 不正 row の fail-loud（silent skip なし）
- vacuous delta bound の RED
- `import.meta.url` 起点（worker cwd 移動に非影響）

**テストファイル**: `tests/guards/single-source-harness.test.ts`
