## 設計決定

1. **`global.gc` unify は semantic 等価の綴り統一** — Node では
   `global === globalThis`（同一 object）で --expose-gac の gc は
   globalThis 直下に露出、browser では globalThis のみ定義。よって
   `if (globalThis.gc)` は (a) Node で同一挙動、(b) browser で
   ReferenceError ではなく feature-miss、(c) typeof guard 不要の
   単一綴り。main-pipeline の typeof guard は `global` が browser 未定義
   であることへの workaround であったため削減し 3 file 同一 shape 化。
2. **blocking-dialog の ALLOWED は破壊操作の gate であることを anchor で
   pin** — `if (confirm('Reset all security metrics?')) reset();` の形を
   正規表現で固定。gate 削除（direct reset() 化）は stale-row + floor +
   anchor の 3 面 RED（MW-079 (c) で実測）。UI flow 外（pipeline・
   library・api code）の blocking dialog は unrostered RED。
3. **useragent-sniffing の ALLOWED は report-only であることを read で
   実証** — production-error-handler の 2 site は telemetry 文脈 object へ
   の field 代入、browser-transcriber :257 は browser 名 diagnostics で
   能力判定は直前の feature detection（`isRecognitionSupported`）。
   UA への**挙動分岐**は class 本義のまま unrostered RED。
4. **legacy-substring の投資不釣合型棄却（3 例目）** — 23 site 全てが
   `substring(0, N)`（0-start 切り詰め）か Math.min/max 正規化 span で、
   class 唯一の incident shape（indexA > indexB 引数 swap）に到達不能。
   fix ゼロの 23 row per-site prose は charCodeAt・Math.max(...xs) と
   同型の投資回避。swap 可能形出現時の再計測を guard header に明示。
5. **minified-boolean-literal の detector は前置演算子文脈 class + 行頭
   形** — `= !0` / `f(!1)` / `a, !0` 等を捉え、`x !== 0` / `a != 1` を
   誤検出しない（`!` の直後が `=` の場合除外は lookahead 不要・
   `[01]\b` が直接排除）。fixture (z7) で両境界を pin。
